## 四、常见报错 → 处置

| 报错 / 现象 | 原因 | 怎么办 |
|---|---|---|
| `⚠️ 分红记录为空 —— 股息率会全为 0` | `finance.STK_XR_XD` 权限或区间问题 | 在**研究环境**里单独跑一次 `finance.run_query(query(finance.STK_XR_XD).limit(5))` 看能不能拿到 |
| `run_offset_query 不可用` | 该函数在当前环境缺失 | 已自动**回退**到 `limit/offset` 分页，不用管；但如果接着报超时，把 `BATCH` 改小 |
| 跑很久 / 卡在某个调仓日 | 全 A 一次拉 5000+ 只行情 | 代码已按 `BATCH = 800` 分批；仍慢就把 `BATCH` 调到 `300` |
| `未成交 N 只` 且 N 很大 | 多半是 **10 万 + 100 股整手**（股价 > 50 元买不进） | 正常现象，日志会打出价格；这也是与本地分叉的主因 |
| 回测跑不完 / 超时 | 聚宽对单次回测有时长限制 | 先把回测区间缩到 `2023-01-02 ~ 2026-09-11` 跑通，再放全长 |
