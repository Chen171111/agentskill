# agentskill — A 股量化策略研究框架

一个 A 股量化策略的**研究 + 回测框架**：数据获取 → 因子计算 → 策略生成 → 风控 → 回测 → 绩效分析，
全链路可复现。另附一套**个人自用**的模拟盘下单链路（Windows + 同花顺，见 §六）。

> ⚠️ **研究与教学用途，不构成投资建议。** 回测是历史模拟结果，不预示未来收益。
> 详见文末[免责声明](#免责声明)与 [LICENSE](LICENSE)。

## 这是什么 / 不是什么

| ✅ 是 | ❌ 不是 |
|---|---|
| 一个能跑的 A 股 ETF / 个股轮动**回测框架**（自动下载数据，clone 下来就能出结果） | 不是"一键赚钱"的实盘系统 |
| 一组**完整的研究记录**：假设怎么被检验、哪些被否定、为什么 | 不是开箱即用的实盘工具（`trader/` 绑死 Windows + 同花顺 + 个人账户） |
| 一份**数据质量踩坑集**：复权判据、口径核对、行业中性化 | 不提供投资建议，不对使用后果负责 |

**先说清楚最重要的一件事**：这个项目的主力策略在这段回测区间里**跑输基准**（见 §三）。
它被保留不是因为收益，而是因为**回撤小一个量级**。如果你在找高收益策略，这里没有。

## 一、快速开始

```bash
pip install -r requirements.txt
python main.py backtest --strategy etf_rotation --pool ETF全球 --topk 5 --rebalance 5 --start 20190101 --end 20260911
```

首次运行会通过 akshare **自动下载行情**到 `data/`（该目录**不入 git**，需要联网）。
数据缓存后，上面这条命令实测约 **4 秒**出结果。

完整步骤（环境要求、数据下载排错、怎么看结果）见 **[QUICKSTART.md](QUICKSTART.md)**。

## 三、实测结果（可复现）

**命令**就是上面那条：

```
策略 etf_rotation ｜ 池 ETF全球 ｜ topk=5 ｜ 5 日调仓 ｜ 2019-01-02 ~ 2026-09-11
基准 = 池内第一只 = 510300.SH 沪深300ETF（可用 --benchmark 覆盖）
```

| 指标 | 策略 | 基准 |
|---|---|---|
| 累计收益 | 28.39% | 51.77% |
| **年化收益** | **3.33%** | 5.61% |
| **最大回撤** | **−9.89%** | −45.10% |
| 夏普 / 索提诺 / 卡玛 | 0.47 / 0.53 / 0.34 | — |
| 年化波动 / 胜率 | 7.59% / 52.52% | — |
| **超额收益** | **−23.38%** | — |

**请正视这个结果**：这条线跑输基准 23 个百分点。保留它的理由不是收益，
是**回撤小一个量级**（−9.89% vs −45.10%）——它是一条**低回撤配置**，不是高收益策略。

> **关于早前版本 README 里出现的 24% / 39.72% 等数字**
> 那些来自**个股动量 + 信号稳定性 + 风险平价**那条研究线，
> 且跑在**数据缺陷修复之前**、**资金口径调整之前**。口径变了之后**不会重现**，
> 因此已从本文移除。研究过程本身保留在 `docs/` 里，供参考。

## 四、架构

```
                    ┌──────────────────────────────────────────────┐
                    │              Scheduler（调度层）              │
                    │        每个交易日尾盘自动触发 run_once        │
                    └───────────────────────┬──────────────────────┘
                                            ▼
   ┌────────────┐   ┌────────────┐   ┌────────────┐   ┌────────────┐
   │ dataprovider│ → │  factors   │ → │ strategies │ → │    risk    │
   │  数据层     │   │  因子层    │   │  策略层    │   │  风控层    │
   └────────────┘   └────────────┘   └────────────┘   └─────┬──────┘
                                             ▲                ▼
                                  ┌──────────┴───────┐  ┌────────────┐
                                  │ trader（执行层）  │←─│  account   │
                                  │ broker + execution│  │  账户/持仓  │
                                  └───────┬──────────┘  └─────┬──────┘
                                          ▼                   ▼
                                  ┌──────────────────────────────────┐
                                  │      storage（SQLite 持久化）      │
                                  │   orders / equity / positions     │
                                  └──────────────────────────────────┘
```

| 层 | 目录 | 关键文件 |
|---|---|---|
| 数据 | `dataprovider/` | `store.py`（下载/缓存/读取 + **读取时份额折算复权**）、`panel.py`（横截面对齐）、`adjust.py`（复权判据） |
| 因子 | `factors/` | `registry.py`（RSI/MACD/乖离/均线差/动量/量比/涨停/连板）、`engine.py` |
| 策略 | `strategies/` | `base.py`（`generate_weights` 约定）、`builtin.py`、`registry.py` |
| 风控 | `risk/` | `manager.py`（单标的上限、总仓位、止损/止盈/回撤止盈） |
| 回测 | `backtest/` | `engine.py`、`account.py`（手续费/滑点/印花税） |
| 绩效 | `analysis/` | `metrics.py`（年化/夏普/索提诺/卡玛/回撤/波动/胜率/超额） |
| 执行 | `trader/` | `broker.py`（`PaperBroker` 模拟撮合 + `Broker` 抽象基类）、`execution.py` |
| 账户 | `account/` | `portfolio.py` |
| 持久化 | `storage/` | `db.py`（SQLite：orders / equity / positions） |
| 调度 | `scheduler/` | `runner.py`（`DailyRunner.run_once`） |
| 入口 | 根目录 | `main.py`（CLI）、`pipeline.py`（回测流水线）、`server.py`（Web Dashboard） |

### 风控组件（均为可选开关）

| 组件 | CLI | 默认 | 说明 |
|---|---|---|---|
| 回撤熔断 | `--dd-circuit` / `--no-dd-circuit` | **开** | 组合回撤 ≥15% 启动分档降仓（15%→65% 仓、20%→40%、25% 清仓）；修复到 ≤10% 才恢复满仓（滞回带 5%） |
| 波动率目标 | `--vol-target` | **0.15** | 实际波动超目标时等比降仓；传 `0` 关闭 |
| 风险平价加权 | `--risk-parity` | 关 | TopK 内按波动率倒数分配权重，替代等权 |
| 信号稳定性过滤 | `--stability` | 关 | 本期与上期 TopK 重叠度低于阈值（如 `0.8`）则空仓 |
| 大盘择时 | `--timing` | 关 | `ma20` / `abs_mom` / `rsrs` / `bias` |

> 熔断与波动率目标基于**组合净值历史**做决策，会牺牲部分收益换更平滑的曲线。
> 具体效果请自己在你的数据上跑，不要照抄本文档——本仓库已刻意不再列未经复核的收益数字。

## 五、策略与标的池

### 策略（`strategies/registry.py`，8 个）

| 名称 | 说明 |
|---|---|
| **`etf_rotation`** | ETF 轮动（跨周期稳健）：快动量(20) + 风险平价，剔除短期均线噪声 ← **当前实盘用这个** |
| `momentum` | 动量轮动：动量 + 均线趋势双因子打分取 TopK |
| `mean_reversion` | 均值回归：乖离率越低越看好 |
| `cross_moving` | 双均线趋势：`sma_gap` 越强越看好 |
| `multifactor` | 多因子打分：加权横截面得分取 TopK |
| `lianban_lead` | 连板龙头接力：选连板最高标的，情绪门控制空仓 |
| `tech_offensive` | 科技进攻：短期动量 + 趋势广度门 + 集中持仓 |
| `bigorder_etf` | ETF 轮动 + 大单资金流叠加 |

### 标的池（`config.RECOMMENDED_POOLS`）

| 池 | 说明 |
|---|---|
| **`ETF全球`** | 全局轮动池：A股宽基/消费 + 跨境(恒生/纳指/标普) + 黄金/红利/国债 ← **当前实盘用这个** |
| `ETF宽基` / `ETF行业` / `ETF防御` / `ETF稳健` | 宽基 / 行业主题 / 黄金红利国债 / 三者混合 |
| `科技进攻` | 科创50 / 半导体 / 人工智能 / 机器人 / 通信算力 |
| `宽基成长` / `行业轮动` | **指数**池，仅作基准或指标参考 |
| `default` | 4 只可交易 ETF |
| `个股动量` | 特殊池：在 `main.py` 里按沪深300 成分股**动态抽样 20 只**，不在 `config` 中 |

> ⚠️ **指数不可直接交易**。用指数池当交易标的会被 `validate_tradeable` 拦截。

## 六、实盘 / 模拟盘（个人自用，非通用工具）

⚠️ **这部分绑死了项目作者的本机环境**：Windows + 同花顺**经典版**（远航版/极速版不兼容）
+ 个人模拟账户 + 硬编码客户端路径。**别人拿不走**，请勿当作通用实盘方案。

想接自己的模拟盘，看 [docs/同花顺经典版接入指南.md](docs/同花顺经典版接入指南.md)。

### CLI 子命令

```
backtest    历史回测
run         模拟盘单次运行
simulate    选股 → 评估 → 下单（默认 ETF全球 + etf_rotation）
daemon      每日定时自动运行
status      查看持仓 / 订单
reset       清空模拟盘状态（持仓/订单/净值），重新开始
ths-check   测试同花顺连接并读取资金/持仓
```

### 接自己的券商

`trader/broker.py` 的 `Broker` 是抽象基类，实现 `submit(order)` 即可：

```python
from trader.broker import Broker

class MyBroker(Broker):
    def submit(self, order):
        # 调用你的券商 API
        order.status = "filled"
        order.filled_price = order.price
        order.filled_qty = order.qty
        return order
```

然后 `DailyRunner(..., broker=MyBroker())`。

## 七、成本口径与已知陷阱

### 成本（`config.TRADING`）

| 项 | 值 |
|---|---|
| 佣金 | **万 5**（最低 5 元） |
| 卖出印花税 | 0.1% |
| 滑点 | 0.05% |

> ⚠️ 早前版本 README 写的"万3"是**错的**，2026-09-13 已按实际费率改为**万5**。
> 这一改动让 ETF 轮动线年化 **−0.41pp**。如果你看到别处还写着万3，以 `config.py` 为准。

### 三个已经踩过的陷阱（都在 `docs/` 里复盘过）

1. **份额折算会让价格跳变**，不复权就会被当成真实涨跌。
   本项目在**读取时**自动复权（`dataprovider/adjust.py`），判据阈值 `0.35`。
   → [docs/ETF线_复权阈值缺陷.md](docs/ETF线_复权阈值缺陷.md)
2. **ETF 上市时间差异会悄悄压缩回测区间**：`build_panel` 对池子取交集，
   池里只要有一只晚上市的，"全区间 2019~2026"就会静默变成它的起点。
   → [docs/ETF池扩容研究_行业轮动.md](docs/ETF池扩容研究_行业轮动.md)
3. **涨跌幅限制分档**：主板 ETF 10%、双创 ETF 20%、跨境/商品 ETF 10%（"无限制"是误传）。
   拿它当异常判据的阈值会误伤真实涨停。
   → [docs/参考_A股ETF涨跌幅限制.md](docs/参考_A股ETF涨跌幅限制.md)
