### 本轮教训
- **行级批处理脚本的坑**：同一文件多处删行时，后续行号会漂移 → 按**内容**定位而非行号；
  且删"死局部变量"可能删空某个 `if` 块（test_industry_neutral 的 `pl_base`）→
  删完必须 compileall 全量验证（本轮就是它抓到的 IndentationError）。
- **测试灯具要和生产路径一致**：execution 测试第一版没把持仓标的放进 prices，
  其实暴露了一个既有特性——卖出路径用 `prices.get` 无 mark 兜底，池外持仓
  （人工个股）不会被策略自动卖。这是**有意或至少无害**的现状，未改，记录备查。
- 隐式拼接的 f-string：pyflakes 按**拼接起点**报行号，f 前缀在第二段上——
  看报告行号找不到 f 时，往上下文多看两行。

### 教训
- **nan 是 truthy 且比较全 False**：`if px:`/`x <= 0` 这类守卫对 NaN 全线失效，
  数值校验必须显式 isfinite。本次一查就是六处同族漏洞。
- 静态分析（pyflakes）抓"未定义变量"类 bug 极高效（昨天 `detail`、今天
  `SimpleNamespace` 都是它抓的），但抓不了逻辑缺陷——滞回 bug 是人工审出来的。
- 写断言先自己算数值：selftest 滞回测试第一版把 dd=9.5% 当成"滞回带内"，
  实际 ≤10% 就该恢复——测试自己写错比没有测试更危险。
