# MEMORY.md — agentskill 项目长期约定

> 作用域：本仓库（`agentskill`）｜只放**必须照做**的规则，保持简短。
> 单次巡检/运行的细节写当天日志，不要写在这里。

## 仓库是公开的（`github.com/Chen171111/agentskill`，`private: false`）

**硬规则：任何提交到仓库的文件里，不得出现真实账户数据。**

> **性质说明（2026-10-09）**：本项目账户是**模拟炒股（纸面盘）**，数字不是真实资金 ——
> 所以**不构成真实资金泄漏，仓库维持公开即可**。仍照占位符处理，只为对齐既有惯例、
> 并避免将来接入真实资金时留下坏习惯。

- 禁止：现金余额、总资产、持仓股数、委托股数、成交金额、合同号、券商账号/邮箱。
- 写法：用占位符 —— `<金额略>` / `<股数略>` / `<合同号略>`，或只写相对变化（「微降 0.07%」）。
- **例外**：行情价格、标的代码、策略权重、涨跌幅属公开数据，可以写。
- 已由 `tools/selftest.py` 的「文档/记忆不得出现真实账户金额与股数（公开仓库脱敏）」自动拦截。
  该检查会扫 `docs/`、`.workbuddy/memory/` 与根目录三份 md；新增/修改文档后请跑一次 selftest。
- 测试夹具同理：可以照抄**结构**，但值要改成合成值（如统一缩放），别照抄真实持仓。

## 巡检自动化的边界（每日 check_alerts 那条）

- **只报不修**：不得重跑下单、不得改持仓/交易状态、不得触发 `main.py simulate --ths` 等真实链路。
- 判定正常/异常必须**双证据**：脚本退出码 + PowerShell 只读核查计划任务是否在册、是否触发。
- `daily_run.bat` 的 `LastTaskResult` **不可信**（末行 `echo [done] exit=%errorlevel%` 会冲成 0）；
  判成败看 `state/last_run.json` 的 mtime + 日志里的 `[done] exit=`。
- 涉及环境阻塞（权限、凭据、安全策略拦截）→ **立刻告知主人，不要绕**。

## 交易链路的已知硬约束

- **同花顺表格 OCR 必须 `psm 4`**（`trader/ths_uia.py` 的 `_OCR_PSM`）。`psm 6` 会把带水印的
  宽表切成两块、只保留第一块 → 持仓 3 行只读出 1 行 → 对账连续拒单（2026-10-23 实测，两天不能交易）。
  `psm 11/12` 会把表按列切成几十行，`parse_position` 全丢。selftest 第 32 条守着这个值。
- **`state/diag_pos_*.txt` 是对账失败的第一诊断入口**：先看「原始 OCR 文本」里该行在不在，
  据此区分「OCR 没读到」与「解析层吃行」，不要一上来就怀疑解析。
- **`tools/probe_env.py` 的 `trade_window=MISS` 在 2026-10-23 之前是假数据**（`EnumWindows`
  回调裸 `return` 导致枚举提前终止，已修）。历史日志里 10-19 / 10-22 / 10-23 的 MISS 都不能当
  「客户端没开」的证据；判客户端是否在跑，看 `[env] ths_proc` 那几行。
- `daily_run.bat` **必须保持纯 ASCII**（含 `chcp 65001` 时，任何非 ASCII 字节都会让 cmd 解析错位、静默丢步骤）。
- 参数透传口径改动（如 `topk=None`）**必须枚举全部消费方**：`pipeline.run_backtest` 与
  `scheduler/runner.py`（实盘 DailyRunner）都要有守卫 —— 2026-10-09 调仓日崩溃就是这么来的。
- 低频分支（调仓每 5 次成功运行才走一次）的改动，交付前必须主动构造样本跑到。
