### 本次新学到的（可复用）

1. `daily_run.bat` 的 `LastTaskResult` **不能作为成败依据**，真实结果看 `state/last_run.json` + 日志 `[done] exit=`。
2. 判断「交易步骤今天是否真跑过」的最快硬证据 = `state/last_run.json` 的 mtime 是否被今天更新。
3. 本机 Bash 下 `cmd //c <bat>` 可执行探针脚本，但 bat **必须 ASCII + CRLF**；
   UTF-8 的 bat 会被 cmd 按 GBK 解析，导致整行错乱（实测复现）。
4. 本机 `cmd.exe` 的「系统找不到指定的路径。」/ Python 的 `WinError` 都是**中文**，
   code page 65001 也不改变这一点 —— 日志里的**英文**同类报错即可判定非二者所出。
