## 数据体检（个股线）—— 结论：地基干净

**背景**：ETF 线出过「份额拆分未复权」事故（4 处跳变污染全部回测，修完 +0.98pp）。
个股线用的是另一份数据（腾讯 `qfq` 前复权），此前从未做过同等体检。

**新增脚本**
- `tools/diag_stock_data.py` —— 体检主脚本（不可能收益 / 非正价格 / 因子 inf /
  前复权 vs 不复权 / 不复权核实）
- `tools/diag_stock_ret_clip.py` —— 涨跌停截断对照（重建干净价格路径后重跑）

**判据**：A 股有涨跌停 → `|日收益|` 超限的行不可能来自正常交易；
但必须区分 ①真实复牌首日（无涨跌幅限制）与 ②前复权口径产物
（qfq = 真实价 − 累计分红，分母趋零 → 收益爆炸）。区分手段 = **拉不复权数据对照**。

**结果**
| 项 | 数字 |
|---|---|
| 不可能收益 | 15,975 行 / 1,119 只（0.177%）= 102 真实复牌 + 15,873 口径产物 |
| 不复权核实 25 只 / 6,311 行 | **6,310（99.98%）**真实收益仍在限内 → 口径产物；真错误 **1 行** |
| `close<=0` / `amt<=0` | 4,416 / 4,410 行（24 只高分红老股）→ **池内 = 0 行** |
| 池内因子 inf | **1 行 / 6,552,602 行**（rev120）；NaN 仅 1,560（暖机） |
| 前复权/不复权价格比 | 随机 40 只中位 **0.980**，错杀 **1/68,464 = 0.00%** |
| 截断对照 | 800: 16.31→**16.38**（+0.07pp）；1200: 16.89→**16.80**（−0.09pp）；夏普 Δ 0.00 |

**→ 本线全部结论无需因数据问题重算。**

**顺带发现**：`bars_all.parquet` 里**本就不含 ST/退市股**
（245 只 `is_st=True` 代码一条都没有）→ 引擎的 ST 过滤是 **no-op**。
已把 `backtest_stock.py` 与 `diag_stock_ret_clip.py` 的打印改成显式提示，
不再出现「剔除 245 只：5260 → 5260 只」这种看着像生效、实则空转的输出。

**自己踩的两个坑（都记进了 skill）**
1. 抽样偏差：对比前复权/不复权时先刻意抽了「24 只负价 + 40 只低价 + 20 只随机」，
   得错杀率 13.89%；换纯随机 40 只后是 0.00%。**总体估计只能用随机样本。**
2. 标签 ≠ 实现：体检脚本打印「因子层污染（池内）」却没做池子过滤，
   得 4~6 个 inf；补上真实过滤后是 1 个。**没人会质疑一个"看起来对"的标签。**
3. `Series.where(cond, other)` 语义是「cond 为 True 处保留原值」——
   截断脚本写成 `raw.where(hit, clipped)` → 异常行原封不动，等于没截断，
   却照样输出了一份"看起来合理"的对照。正确：`raw.where(~hit, clipped)`。
   **教训：数据变换必须有「变换后差异行数 = 预期行数」的断言**（这里是 15,975）。

### 二、⚠️ 撞见并修掉「腾讯 qfq 仿射复权」缺陷

顺手拿不复权价对照，发现 **`bfq = k·qfq + m`**（仿射），**不保持日收益**：
- 中国神华 SH601088：k=1，m=15.57（纯减法）
- 兖矿能源 SH600188：k≈1.96（有送转）
- 判据：同一天 O/C/H/L 四个价位 —— diff 恒定=减法、ratio 恒定=乘法、都不恒定但 (k,m) 拟合极好=仿射

**后果**：qfq 口径日收益被放大约 `bfq/qfq` 倍。
中国神华 2019-01-04 真实 **+2.15%**，qfq 口径 **+17.92%**（8.3 倍）。
池内 6,730,339 行：放大 **>1.05 占 28.2%**、>1.10 占 14.9%、>1.25 占 4.2%。
`放大倍数 = 1 + m/qfq` → **qfq 越小放大越狠**，偏袒反转策略。

**⚠️ 关键方法论**：「涨跌停」判据**抓不到它**（放大是渐进的，0.5%×8=4.2% 在限内）。
截断法测出影响 −0.05pp，重建法测出 **−0.89pp** —— **低估 10 倍**。

**修正**：
- 新增 `tools/fetch_stock_bfq.py` → 不复权日线 + **真实成交额** + 换手率
  （`newfqkline` 直接给成交额，旧笔记说"不可得"是错的）
  → 抓 **5,457 只 / 9,418,384 行**，2018-01-02~2026-09-11，成交额 100% 非空
- 新增 `tools/rebuild_returns.py` → 分红/送转回放 → `data/stockbars/bars_total.parquet`
  → 重建后 |日收益| 超涨跌停的行：**15,975 → 464**
- 新增 `tools/diag_qfq_adjust.py`（诊断）、`tools/diag_qfq_impact.py`（影响量化）

**修正结果**（`hold=20` 排名加权）：

|---|---|---|---|
| topk=800 年化/夏普 | 16.31% / 0.74 | **15.83% / 0.74** | −0.48pp |

## 股息率策略首轮检验（步骤 4）—— 「换慢信号」方向可行

主人首选方向（高股息型）的首轮完整检验。新增 `tools/test_dividend_factor.py`、
`tools/backtest_dividend.py`，文档 `docs/个股线_股息率策略.md`。

### 结论一：股息率**不是"强信号"，是"慢信号"**

| 因子 | 60 日 IC |
|---|---|
| `vol20` | 0.0935 |
| `max20` | 0.0897 |
| `rev20` | 0.0752 |
| **`dy_ttm`** | **0.0605** |

股息率 IC 只有 0.0605，**不比现有因子高**。且**只有 5/8 年为正**（2021/2024/2025 为负），
十分位顶底差 +3.50pp 且**非单调**（最高是 D9 12.31%，D10 反而 11.92%）。
样本内 0.0756 → 样本外 0.0428。

→ **主人的方向对，但措辞要改：是「换『慢』信号」，不是「换『强』信号」。
价值在换手：2.9x vs 多因子的 8.2x。**

### 结论二：朴素「高股息 top-N」跑不赢指数，加过滤器后才行

| 过滤 | 样本内 2019~2022 | **样本外 2023~2026** |
|---|---|---|
| 裸 top-N=20 | 6.29% | **4.48%** |
| `max_dy≤10%` | 18.52% | **7.40%** |
| `min_div3≥2` | 19.29% | **8.59%**（夏普 0.54、回撤 −23.6%）|
| 中证1000 | 9.30% | 4.03% |
| 国证2000 | 11.54% | 5.85% |

阈值是**平台**不是刀尖（`max_dy` 8~12% 都改善、`min_div3` 2~3 都改善）。
但 **`N` 不稳健**（样本内最优 50、样本外最优 10）→ 取 20~30 居中。

### 结论三：**10 万从"做不了"变成"能做"**

| | 多因子（弱信号×高换手） | 股息率（慢信号×低频） |
|---|---|---|
| 持仓 | 763 | 20 |
| 年换手 | 8.2x | 2.9x |
| **10 万真实年化** | **−7.67%（不可行）** | **样本外 ≈ +8.3%（可行）** |
| 样本外超额 vs 中证1000 | — | **+4.3pp** |

最低佣金额外成本仅 **0.29pp/年**（vs 多因子的 7.5pp+）。

### ⚠️ 五个必须写进报告的局限

1. **用样本外 8.59%，不能用全区间 16.44%** —— 衰减 **55%**，夏普 0.96 → 0.54
