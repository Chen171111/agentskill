## 顺带发现：`hyst`（四进三出）**一直退化成 topn**，此前从未被真正测试

### 证据

`results/tax10_dividend_backtest.csv` 里 `topn` 与 `hyst` **24 个配置的 8 项指标
逐行完全相同，最大绝对差 = 0.0**。

### 机制（读代码可确认）

`dy` 先被 `min_dy=0.5` 过滤；`hyst` 的候选集 = `{dy≥entry}` ∪ `{已持有且 dy≥exit}`。
**只要「dy≥4% 的股票数」恒 ≥ N，候选集就包含 dy 的前 N 名**
→ `cand.nlargest(N)` 与 `dy.nlargest(N)` 选出同一批 → **滞回阈值毫无约束力**。
实测 `N ≤ 50` 时恒成立。

### 阈值调高让它生效后，确实更好（`--entry 8 --exit 6`，`≥2次` 过滤）

| 区间 | `topn` | **`hyst`** | Δ | `hyst` 平均持仓 |
|---|---|---|---|---|
| 样本内 2019~2022 | 19.29% / 0.96 | **20.54% / 1.00** | **+1.25** | 16.3 |
| **样本外 2023~2026** | 8.59% / 0.54 | **10.89% / 0.65** | **+2.30** | 19.2 |

- **平均持仓 < 20 证明阈值真的生效**；换手还更低（3.01 → 2.82）
- **样本外改善更大 → 无衰减**
- **改善不是「持仓变少」带来的**：`topn` 的 N 越小越差（N=10 → 2.99%），
  而 `hyst` 持仓更少却更好 → 是**滞回机制本身**的贡献

## 2. ⚠️ 判据修正：「阈值是否生效」不能用「平均持仓 < N」

实测 `entry=8/exit=4` 在样本外**平均持仓仍是 19.98 ≈ N**，但年化 11.35% ≠ 基线 8.59%
→ 掩码确实变了（`keep` 把已持有股票留在候选集里，挤掉了别的），被误判成"没生效"。
**正确判据：结果与基线不同（掩码不同）。**（已写进 `tools/README.md` 铁律 8）

## 3. ⚠️ 功劳分解：**门槛效应 + 滞回效应，各约一半**（对照实验）

`hyst` 同时做了两件事：① 提高股息率门槛 ② 保留已持有股票。必须拆开。
对照 = 纯门槛 `topn`（`min_dy = entry`，不做滞回）：

| 区间 | 门槛效应 | 滞回效应 |
|---|---|---|
| 全区间 | +1.98 | +0.85 |
| 样本内 | +1.75 | +3.47 |
| **样本外** | **+1.36** | **+1.40** |

→ **修正我早先的判断**（原写"改善来自滞回机制本身"）。
「不是持仓变少」仍成立且更强：`hyst` 持仓比纯门槛**还多**（样本外 19.98 vs 18.11）。

**机制**：股息率 = 每股分红 ÷ 股价 → **股价上涨会让股息率被动下降** →
朴素 `top-N` 会因此**卖掉上涨的股票**（逻辑荒谬）→ `hyst` 的 `exit` 把它保留住。
