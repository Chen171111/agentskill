## 2. ⚠️ 检测出研究口径缺陷（本次最重要的发现，已立项未修）

**文档：`docs/个股线_送转调整口径缺陷.md`**（8 节）

`tools/test_dividend_factor.py::build_yield_panel` 第 96–104 行：

```python
adj[i] = Π_{j>i} (1 + r_j)      # j 遍历**全部分红历史**，不设上界，而且是**乘**
```

两个错，互相独立：**① 方向反了**（该除该乘）**② 时间上没上界**（t 之后的送转被算进 t 之前的 DPS）。

### 判据（决定性）：**送转是价值中性的**

> 1 股变 2 股、股价腰斩、每股分红摊薄一半 → **纯送转除权日前后，股息率不应该跳变。**

`joinquant/_verify_core.py` 第二部分实测（37 个「纯送转 + 前 1 年内有现金分红」事件，
24 个有可用价格，配 `bars_bfq` 不复权真实价）：

| 口径 | 公式 | **dy 在送转日的中位比值** | 偏离 1 | 偏离 (1+r) |
|---|---|---|---|---|
| **L 现行** | `Σ D_i·Π_{k>i,全部}(1+r_k)` | **1.446** | 0.446 | **0.031** ← 精确贴合 |
| W 只去未来送转（仍乘） | `Σ D_i·Π_{i<k≤t}(1+r_k)` | 2.060 | 1.060 | 0.639 ← 更糟 |
| **C 正确** | `Σ D_i / Π_{i≤k≤t}(1+r_k)` | **1.008** | **0.022** | 0.401 ← **连续** ✓ |

逐样本也对得上：`SZ300442` 2023-05-24、`1+r=1.80` → 比值 L **1.83** / C **1.01**。

**C 的推导**：在 `i` 的除权日持有 1 股，到 `t` 时变成 `Π_{i≤k≤t}(1+r_k)` 股；
那笔现金摊到「当前每股」上要**除**这个因子。

### 影响面（已量化）

| 指标 | 值 |
|---|---|
| 有分红的 (股票, 除权日) 组合 | 5689 个 |
| 两口径不一致 | **1658 个（29.14%）** |
| DPS 比值 中位 / 均值 / 90分位 / 最大 | **1.633** / 2.026 / **3.242** / **17.55** |
| 比值 > 2× / > 5× / > 10× | 9.23% / 0.62% / 0.07% |

⚠️ **不等于「选股名单会变 29%」** —— `≤10%` 上限会挡掉一部分被放大到离谱的标的（尤其高送转股），
实际影响更小，**具体多大必须修完跑对照回测才算数**。

### 两个边界澄清（避免误伤）

1. **`tools/rebuild_returns.py` 的送转处理是对的**（`ret = (close·(1+r) + D)/prev − 1`，标准总收益公式）
   → **总收益序列不受影响**；**多因子 8 因子线与 ETF 线不牵动**，只污染「股息率数值」
2. **实现来源只有一处** —— 全库搜 `BONUS_IT_RATIO` / `adj`：`backtest_dividend` /
   `test_industry_neutral` / `paper_track_dividend` / `sweep_hyst` / `sweep_dividend_into_mf` /
   `diag_dividend_into_mf` 全部 **import 它** → **改一处即可**
   （对照 `docs/ETF线_复权阈值缺陷.md` 那个「四处实现、改了一处没回灌」的教训，这次没这个问题）

### 处理方式：**不擅自改研究口径**，只在聚宽文件加开关

`jq_dividend.py` 加了 `ADJ_MODE = 'legacy' | 'correct'`，**默认 legacy**（复刻本地，保证两边可比）。
改一行就能在聚宽上跑修正口径 → **这是成本最低的外部交叉验证途径**。

**为什么不在本地直接修**：修它会牵动全部历史结论（年化 / 样本内外 / `N`·`hold` 邻域 /
Brinson / `hyst` 阈值检验 / 红利税）→ 属独立的研究口径变更，已按主人要求**单独立项**
（5 条任务，含 6 条验收判据与三种可接受结局）。

## 4. 离线自检（本项目方法论的新工具，值得复用）

**聚宽代码没法本地跑，但可以「伪造 SDK」让它能被 import**：

```python
class _Any:                      # 哑对象：让 query(...).filter(...) 能构造
    def __getattr__(self, k): return _Any()
    def __call__(self, *a, **k): return _Any()
    def __eq__(self, o): return _Any()   # 比较运算符也要返回 _Any 才能串起 filter

class _FakeFinance:
    STK_XR_XD = _Any()
    def run_offset_query(self, q): return RAW[0]   # ← 注入本地数据（按聚宽字段名）
    def run_query(self, q): return RAW[0]

jq = types.ModuleType('jqdata'); jq.query = lambda *a, **k: _Any(); jq.finance = _FakeFinance()
sys.modules['jqdata'] = jq
spec = importlib.util.spec_from_file_location('jq_dividend', path)
mod = importlib.util.module_from_spec(spec); spec.loader.exec_module(mod)
mod.log = SimpleNamespace(info=..., warning=..., error=...)   # 伪造聚宽全局
mod.g   = SimpleNamespace(div=None)
```

于是可以调 `mod._load_dividends()` / `mod._yield_at()`，与本地实现**逐值比对**。
**结论：5732 个 (股票, 除权日) 组合，`dps_ttm`/`n_div3` 不一致 0 个**。

**自检里自己踩的坑**：`correct` 分支第一版把 `P(t)=Π(1+r)` 写成**全市场一起连乘**
（而非按 `code` 分组）→ 直接 `overflow encountered in reduce`。
**这就是离线自检的价值** —— 它一眼就把这个错抓出来了。
