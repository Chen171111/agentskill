## 三、结论

### 3.1 核心发现：**动量策略本身没坏，坏的是套在它上面的风控**

- **`H 纯动量` 三项全面优于懒人基准**：
  年化 **11.55% vs 7.67%**、夏普 **0.83 vs 0.60**、回撤 **−26.05% vs −33.86%**。
- 也就是说：**去掉风控覆盖层后，策略跑赢了"等权买入持有"** —— 这与第六节的结论相反。
- **第六节的结论需要修正**：不是"动量无效"，而是"**当前的风控配置把它压垮了**"。

### 3.2 各组件的作用

| 组件 | 实际作用 | 建议 |
|---|---|---|
| **Faber 趋势过滤**（`trend_window=60`） | **年化拖累 2.19pp、夏普拖累 0.29** | ⚠️ 需重验（见 3.3） |
| **风险平价**（`risk_parity`） | **正贡献 2.90pp**，关掉后回撤恶化 11pp | ✅ **保留** |
| 趋势门（`trend_gate`） | 收益 +1.14pp 但回撤 −7.04pp | ⚖️ 取舍，倾向保留 |
| **回撤熔断**（`dd_circuit`） | **差异恰好为 0** | ⚪ **从未触发**，形同虚设 |
| **波动率目标**（`vol_target=0.15`） | 差异 ~0.04pp | ⚪ **基本未触发** |
| `topk=5` → 20 | +0.39pp / 夏普 +0.09 | 轻微，可考虑 |

> **两个风控（回撤熔断、波动率目标）在整段回测里几乎没起作用**——
> 它们被写进 `config.py` 当作"默认甜点组合"，但实测**从未触发**。
> 这是配置与现实脱节的信号，值得单独查阈值设置。

### 3.3 ⚠️ 但这与根 HANDOFF 的记录**直接矛盾**，不能据此改实盘

根 `HANDOFF.md` 明确记录：

> 「2026-09 社区研究落地：Faber 均线趋势过滤默认开启（trend_window=60）。
>   复测 2020-01~2026-08：年化 33.01%→51.19%、最大回撤 −17.05%→−11.98%」

**即：当时的验证显示 Faber 过滤是显著正贡献。而本次实测显示它是拖累。**

**矛盾必须查清才能动**，可能来源：
1. **区间不同**：HANDOFF 是 2020-01~2026-08；本次含 2019 年
2. **池子不同**：HANDOFF 未注明池子，实盘是 `ETF全球`
3. **配置不同**：topk、rebalance、是否 risk_parity 等

**在复现它当时那套验证、并解释清楚差异之前，不应改动实盘。**

> ✅ **已复现并解释 —— 见第四节。**
> 结论：**矛盾来自区间差异，不是谁错了。**
> 同一池子同参数下，含 2019（强牛）时 Faber 为 **−2.19pp**、不含 2019 时为 **+2.13pp**。
> 跨 21 个配置统计，**Faber 在 71% 的组合里是正贡献**，在实盘池 `ETF全球` 的所有 topk 上都为正
> → **HANDOFF 当年开启 Faber 的判断站得住。**
> 但 Faber 是 **regime 依赖**的择时器，**单次回测无法判定去留，必须做滚动样本外**。

### 3.4 本次归因的自身局限（必须承认）

- **H 是"试了 9 个变体后挑出来的"** —— 这本身带选择性偏差。
  缓解证据：H 在**样本外同样成立**（OOS 年化 12.80% / 夏普 0.96 vs 基准 10.68% / 0.87）。
  但这仍不足以替代一次**事先定好假设的验证**。
- 只测了"关掉"没测"调参"（如 trend_window 取 20/120/250）。
- 未做**滚动样本外**（用滚动窗口选配置 → 随后验证），而这才是选配置的正确方法。

## 四、矛盾的复现与解释（已完成）

> 脚本：`tools/reproduce_faber_validation.py` ｜ 结果：`results/faber_reproduce.csv`
> 扫描「池子 × topk」共 21 个组合，区间固定为 HANDOFF 记录的 `2020-01~2026-08`。

### 4.1 未能精确复现 51.19% / 33.01%

21 个组合里**没有一个**给出 51.19%（开 Faber）与 33.01%（关 Faber）。
最接近的是 `科技进攻`（26~35% 区间），但它含 2024~2025 才上市的新 ETF，
`build_panel` 取交集后**数据未覆盖 2020 年起**，无法与 HANDOFF 的区间对齐。

**诚实结论：无法精确复现。** 可能原因：① 当时用的是本文档看不到的配置；
② `data/stocks/` 的行情已被后续 `refresh_data.py` 更新过（数据 vintage 不同）。

> 一个耐人寻味的细节：`ETF全球` / topk=5 / 关 Faber 的回撤 **−17.05%**
> 与 HANDOFF 记录的"关 Faber 回撤 −17.05%"**完全相同**。
> 但年化对不上（本次 3.35% vs 记录 33.01%），**故不足以认定是同一配置**。

### 4.2 但**方向**可以复现，而且矛盾被完整解释

**同一个池子、同一个 topk、同一套参数，只改区间：**

| 区间 | 开 Faber | 关 Faber | Faber 净贡献 |
|---|---|---|---|
| **2020-01 ~ 2026-08**（HANDOFF 的区间） | 5.48% | 3.35% | **+2.13pp**（正）✓ |
| **2019-01 ~ 2026-09**（本次归因的区间） | 2.49% | 4.68% | **−2.19pp**（负）✓ |

**两者都对——差别只在「有没有包含 2019 年」。**

**2019 年是强势牛市**（沪深300 +36%、创业板 +43%），而 Faber 用 60 日均线确认趋势，
**在 2019 年初的快速反弹里入场偏慢**，因此单独这一年就足以把符号翻过来。

### 4.3 跨配置统计：Faber 在多数情况下是**正贡献**

21 个「池子 × topk」组合中，**Faber 为正贡献的有 15 个（71%）**：

| 池子 | Faber 净贡献（年化 pp，均值 / 最小 / 最大） |
|---|---|
| **ETF全球（实盘在用）** | **+3.20 / +0.62 / +6.85** |
| ETF稳健 | +1.95 / +0.64 / +3.26 |
| default | +2.60 / +2.45 / +2.90 |
| 科技进攻 | +2.65 / −0.75 / +8.64 |
| ETF防御 | +0.30 / +0.30 / +0.30 |
| ETF行业 | −0.66 / −1.16 / −0.39 |
| ETF宽基 | −1.41 / −4.26 / +0.56 |

→ **在实盘池 `ETF全球` 上，Faber 在 2020~2026 的每个 topk 上都是正贡献。**
HANDOFF 当年"复测有效才开启"的判断**是可以站住的**。

### 4.4 真正的结论：Faber 的价值**随区间剧烈波动**，不能用单次回测定案

- 包含 2019（强牛）→ 它是拖累
- 不含 2019（更多熊/震荡）→ 它是正贡献
- 差异幅度 **4.3pp/年**，全部来自一个年份

**这不是"Faber 好或不好"的问题，而是"它是个 regime 依赖的择时器"**——
它的贡献取决于样本里恰好有多少个"趋势破坏"的时段。

> **因此：本次归因第 3.3 节的矛盾已解决，但结论不是"该关掉 Faber"，
> 而是"单次回测无法判定 Faber，必须用滚动样本外"。**

## 五、长样本判定（2015~2026，12 年）—— Faber 的最终结论

> 脚本：`tools/faber_long_sample.py` ｜ 结果：`results/faber_long.csv`
> 关键前提：`ETF全球` 池**数据交集起点 2014-01-15**（最晚上市的是 513500），
> 故回测可从 **2015-01-01** 起 → **约 12 年样本**，远长于此前 7.7 年。

### 5.1 Faber 开/关 在各区间

| 区间 | 开 Faber (tw=60) | 关 Faber (None) | Faber 净贡献 |
|---|---|---|---|
| **长样本 2015~2026** | 6.83% / 夏普 0.45 / 回撤 **−18.71%** | **8.80% / 夏普 0.56 / 回撤 −14.41%** | **−1.96pp / 夏普 −0.11** |
| 2015~2019 | 12.35% / 0.57 | **15.71% / 0.69** | **−3.37pp / −0.12** |
| 2020~2026 | **5.41% / 0.68** | 3.20% / 0.43 | **+2.21pp / +0.25** |
| 2015~2022 | 9.89% / 0.55 | **11.18% / 0.60** | −1.29pp / −0.06 |
| 2023~2026 | 2.78% / 0.39 | 2.52% / 0.45 | +0.27pp / −0.06 |

**4 个子区间中 3 个支持「关」，长样本也支持「关」。**

### 5.2 一个反直觉但重要的细节

**Faber 的本职是"控制回撤"，但长样本上它的回撤反而更差**（−18.71% vs −14.41%）。

→ 说明它**不是在降低风险，而是在错误的时间卖出、然后错过反弹**。
这与"趋势过滤应该改善回撤"的预期相反，也是它净贡献为负的机制。

### 5.3 滚动切换依然无效

长样本上滚动决策（回看 3 年 → 持有 1 年，共 9 次决策，选开 5 / 选关 4）：

| 配置 | 年化 | 波动 | 夏普 | 回撤 |
|---|---|---|---|---|
| 始终开 Faber | 6.83% | 17.26% | 0.45 | −18.71% |
| **始终关 Faber** | **8.80%** | 17.01% | **0.56** | −14.41% |
| 滚动决策（样本外） | 3.20% | 7.06% | 0.48 | −12.11% |

**滚动决策（0.48）劣于"始终关"（0.56）→ 切换是负贡献。**
（与前一轮 7.7 年样本的结论一致：用"过去 N 年夏普"判断 Faber 无效。）

### 5.4 最终结论与建议

**证据指向：`trend_window=60` 在长样本上是净负贡献（收益 −1.96pp、夏普 −0.11、回撤还差 4.3pp）。**

| 支持「关」 | 支持「开」 |
|---|---|
| 长样本 2015~2026：收益/夏普/回撤**三项全输** | 2020~2026：+2.21pp / 夏普 +0.25 |
| 2015~2019：−3.37pp | 21 个「池×topk」组合（2020~2026 区间）：71% 为正 |
| 2015~2022：−1.29pp | 根 HANDOFF 当年的验证（**本次无法精确复现**） |
| 2023~2026：夏普 −0.06（基本持平） | |

**建议（需主人决策，我未改动实盘）**：

1. **倾向关闭 Faber**：长样本 + 3/4 子区间支持，且**回撤同时改善**，
   不存在"用回撤换收益"的取舍。这是一个**简化**（减少一个组件），
   通常也意味着更低的实现风险。
2. **但两点必须先说清**：
   - 它与根 HANDOFF 的记录矛盾，而**那次验证我无法精确复现**
     （见第四节 4.1），意味着我可能没找到它当时的真实配置。
   - **改动会影响实盘下单行为**（当前模拟盘持有 300 股 510880）。
3. **稳妥路径**：先把 `trend_window` 改为可配置开关并**并行跑一段模拟**
   （Faber 开 / 关 两套同时记录），用真实前向数据确认后再切。
   **不要仅凭回测直接改实盘。**

> **本轮结论的可信度说明**：这是本次会话中关于 Faber 的**第三次修正**
> （① "它是拖累" → ② "区间依赖、多数为正" → ③ "长样本上确实为负"）。
> 前两次都是**样本长度不足**导致的片面结论。**12 年样本是目前能拿到的最长样本，
> 但仍只有一个 12 年窗口——不是多次独立验证。**
> 因此上述建议的强度是"**值得改，但应走并行验证**"，不是"立刻改"。
