# 个股线：复权口径缺陷 —— 腾讯 `qfq` 是**仿射复权**，不保持日收益

> 2026-09-15 ｜ 脚本：`tools/diag_qfq_adjust.py`、`tools/rebuild_returns.py`
> 缘起：补做「分红数据可得性」时，顺手拿不复权价对照，撞见了这个

---

## 一、问题

腾讯 `fqkline` / `newfqkline` 返回的 `qfq`（前复权）**不是标准的乘法复权**，
而是一个**仿射变换**：

```
bfq = k · qfq + m
```

- **中国神华 SH601088**（无送转）：`k = 1`，`m = 15.57`（2019 年）→ **纯减法**
- **兖矿能源 SH600188**（有送转）：`k ≈ 1.96`，`m ≈ 10.98` → 仿射

**为什么这是问题**：只有**乘法**复权保持日收益。

| 复权口径 | 日收益是否保持 |
|---|---|
| 乘法（标准前复权） | ✅ 保持 |
| **减法 / 仿射（腾讯）** | ❌ **放大**，倍数 = `bfq/qfq` |

实测（中国神华 2019-01-04）：

| | 收盘价 | 当日收益 |
|---|---|---|
| 不复权（真实） | 17.690 → 18.070 | **+2.15%** |
| qfq 口径 | 2.120 → 2.500 | **+17.92%** |

**同一天，真实涨 2.15%，qfq 口径算出涨 17.92% —— 放大 8.3 倍。**

---

## 二、证据：怎么判定它是仿射而不是乘法

对**同一天**的 `open/close/high/low` 四个价位分别比较，三种口径的特征完全不同：

| 口径 | `bfq − qfq`（diff） | `bfq / qfq`（ratio） |
|---|---|---|
| 减法 | **恒定** | 变化 |
| 乘法（标准） | 变化 | **恒定** |
| 仿射 | 变化 | 变化，但能被一组 `(k, m)` 完美拟合 |

**实测（2021-11-04）**：

中国神华 SH601088 —— diff 恒为 **11.6200**（四个价位都一样），ratio 在 2.36~2.56 之间跳：

| 日期 | qfq O/C/H/L | bfq O/C/H/L | diff（O/C/H/L） |
|---|---|---|---|
| 2021-11-04 | 8.210 / 8.520 / 8.570 / 8.100 | 19.830 / 20.140 / 20.190 / 19.720 | **11.62 / 11.62 / 11.62 / 11.62** |
| 2021-11-05 | 8.410 / 7.880 / 8.410 / 7.880 | 20.030 / 19.500 / 20.030 / 19.500 | **11.62 / 11.62 / 11.62 / 11.62** |
| 2021-11-08 | 8.130 / 8.170 / 8.330 / 7.860 | 19.750 / 19.790 / 19.950 / 19.480 | **11.62 / 11.62 / 11.62 / 11.62** |

→ **diff 恒定到小数点后 4 位，ratio 却每天在变** = 纯减法。

兖矿能源 SH600188 —— diff 每天在变（17.60 / 16.89 / 17.19 …），
但四个价位能被一组 `(k≈1.955, m≈10.98)` 拟合，残差 < 0.01 元：

| 日期 | qfq C | bfq C | diff | 仿射拟合 |
|---|---|---|---|---|
| 2021-11-04 | 6.940 | 24.540 | 17.600 | 1.957 × 6.940 + 10.958 = **25.185**（H 实测 25.180）|
| 2021-11-05 | 6.190 | 23.080 | 16.890 | 1.952 × 6.190 + 10.997 = **24.759**（H 实测 24.760）|

→ **不是减法，也不是乘法，而是仿射**（腾讯把送转按乘法、现金分红按减法处理）。

### 2.1 脚本复现（`tools/diag_qfq_adjust.py --sample 5`）

```
  代码        日期               k         m      最大残差   判定
  SH601088  20211231    1.0000   11.6200    0.0000   减法（diff 恒定）
  SH600188  20211231    1.9327   11.1228    0.0032   **仿射** k=1.933≠1
  SZ000002  20211231    1.0000    1.6400    0.0000   减法（diff 恒定）
  SH600844  20211231    1.0000   -0.0000    0.0000   减法（diff 恒定）
  SZ002221  20211231    1.0000    0.2100    0.0000   减法（diff 恒定）
  SH600874  20211231    1.0000    0.8300    0.0000   减法（diff 恒定）
  SZ300365  20211231    1.0000    0.0300    0.0000   减法（diff 恒定）
  SZ000780  20211216    1.0000    0.0000    0.0000   减法（diff 恒定）
```

**读法**：多数股票 `k = 1`（**退化为纯减法**），只有**做过送转**的股票 `k ≠ 1`（真仿射）。
`m` 就是「未来累计每股现金分红」——`m = 0` 的股票（如 SH600844、SZ000780）
其 qfq 与 bfq **完全相等**，不受影响。

**→ 所以"哪些股票被影响"是可判定的：`m > 0` 的股票才受影响，且 `m/qfq` 越大越严重。**

### 2.2 一句话概括这个口径

> 腾讯的 `qfq` = **现金分红用减法、送转用乘法** 的混合口径。
> 它把**分红当"价格平移"**处理，而分红在真实世界里是**收益** ——
> 平移会改变收益率的分母，所以**除权日之外的每一天收益都被放大了**。

放大倍数 = `bfq/qfq = 1 + m/qfq`，其中 `m` = **未来累计每股现金分红**。
所以：**`qfq` 越小（跌得越惨）放大越狠**。

### ⚠️ 为什么这比之前的「15,975 行异常」严重得多

`docs/个股线_数据体检.md` 用「`|日收益|` 超涨跌停」作判据，只抓到了 **15,975 行（0.177%）**，
并据此得出「影响很小」。**那个判据对这个问题是失效的**：

> 放大是**渐进的**。真实涨 0.5% 的股票，放大 8 倍后是 4.2% —— **远在涨跌停之内，不会被判据抓到**，
> 但它的 `rev5/20/60/120`、`vol20`、`max20`、`illiq20` 全部被放大了 8 倍。

即：**「超涨跌停」只覆盖了放大效应的尾巴，主体藏在判据的盲区里。**

而放大最狠的恰是 **`qfq` 接近 0 的股票 —— 跌得最惨的那批**，
正是反转策略（`revN` 高分）要买的标的。所以这个偏差**方向性偏袒策略**，必须查。

## 四、修正方法：不复权价 + 分红回放

标准做法（也是 `HANDOFF_项目总结与下一步.md` §五「根治方案」说的那条）：

对每只股票、每个交易日 `t`：

- **非除权日**：`ret(t) = bfq_close(t) / bfq_close(t−1) − 1`
- **除权日**（当日每股派现 `D`、每股送转 `r`）：
  `ret(t) = (bfq_close(t) × (1+r) + D) / bfq_close(t−1) − 1`

再累乘成连续价格路径。

**用到的数据**（本次都已就位）：

| 数据 | 来源 | 文件 |
|---|---|---|
| 不复权日线 + **真实成交额** + 换手率 | 腾讯 `newfqkline`，`kind=bfq` | `data/stockbars/bars_bfq.parquet` |
| 分红送配（除权日、每10股派息、送转比例） | 东财 `RPT_SHAREBONUS_DET` | `data/dividends/bonus_all.parquet` |

**副产品**：`newfqkline` 直接给**真实成交额**，
顺带修掉了两个旧限制（都在 `docs/个股线_数据体检.md` §五记过）：

1. 「真实成交额不可得，只能用 `close×volume×100` 估算」→ **已解决**
2. 「池子门槛用前复权价比较」→ 有了 bfq，`min_price` / `min_amount` 可用**真实价**

### 5.5 结论

1. **策略成立，不是伪 alpha。** 修正后 `topk=800` 年化 **15.83%**、夏普 **0.74**；
   `topk=1200` 年化 **16.43%**、夏普 **0.79**。
2. **年化需下调约 0.5pp**（16.31% → 15.83%）。这是**唯一的量化修正**。
3. **真实成交额带来 +0.4~0.5pp 的正向修正**。
4. **曲线形状、topk 排序、资金门槛结论全部不变。**

> ⚠️ **一个重要的方法论点**：此前 `docs/个股线_数据体检.md` 用「涨跌停截断」做的对照
> 只测出 **−0.05 / −0.07pp**（`topk=800/1200`），比真实影响 **−0.89 / −0.97pp 低估了约 10 倍**。
> 原因正是第三节说的：**截断只抹平了被判据抓到的那 15,975 行，
> 而放大是渐进的、主体在判据盲区里**。
> → **渐进式偏差必须用"重建数据"来测，不能用"打补丁式截断"来测。**

> ⚠️ **我自己也踩了一个坑，值得记下**：`rebuild_returns.py` 第一版用
> `cumprod` 从 **1.0** 起算价格路径，**没有锚定到最新真实价**。
> 而引擎的 `min_price >= 2.0` 是拿**绝对价格**比的 →
> 池子从 **74.6% 塌到 5.1%**，跑出「年化 16.31% → 0.12%」的假结论。
> 已在脚本里加**归一化自检**（重建后价格中位 vs 不复权价中位，比值必须落在 0.5~2.0），
> 不通过直接返回非零退出码。
> **教训：任何"重建价格序列"的操作，都要断言重建后的价格量级与原价一致** ——
> 收益率正确 ≠ 价格量级正确，而绝对价格门槛只看量级。
