## 二、策略全貌（据水印版代码图）

### 定位
**尾盘打板 / 强势股短线策略**，不是配置型多因子。

### 时间轴
- **09:05** `prepare_candidates()` —— 盘前用日线筛候选池
- **14:40** `trade()` —— 尾盘用分时确认并买入

### 盘前日线筛选（5 道）
1. **市值**：总市值 50 ~ 200 亿元（`g.min_market_cap = 50` / `g.max_market_cap = 200`）
2. **排除**：停牌 / ST / 退市风险（名称含 `ST`、`*`、`退`）
3. **量能**：最近 3 日成交量递减（`vol[-3] > vol[-2] > vol[-1]`）
4. **涨停基因**：最近 20 个交易日出现过涨停（`high >= high_limit × 0.999`）
5. **均线多头**：`MA5 > MA10 > MA20 > MA60`

### 盘中分时确认（尾盘 14:40 附近）
6. **当日涨幅**：3% ~ 7%（`g.min_pct=0.03` / `g.max_pct=0.07`，注释标"C版，上限放宽到 7%"）
7. **量比**：> 1（`g.min_volume_ratio = 1.0`）
8. **实时换手率**：5% ~ 10%（由「昨日换手率 × 今日累计量 / 昨日成交量」实时推算）
9. **VWAP 强度**：全天至少 80% 的分钟收盘价在 VWAP 上方（容忍度 0.997）
10. **相对强度**：至少 70% 的分钟走势强于沪深300（`g.min_outperform_ratio = 0.70`）
11. **尾盘突破形态 "V3"**：
    - 14:20 ~ 14:35 寻找尾盘高点（`breakout_start/end`）
    - 阶段高比较区间 14:00 ~ 14:20（`stage_start/end`）
    - 窗口高 ≥ 14:20 前全天高点的 **96%** 才继续判断（`near_day_high_ratio = 0.96`）
    - 突破后至少 70% 的分钟未有效跌破 VWAP（`pullback_ok_ratio = 0.70`）

### 其他设置
- `set_benchmark('000300.XSHG')` 沪深300
- `set_option('use_real_price', True)` 真实价格
- `set_option('avoid_future_data', True)` 无未来数据（作者强调）
- `g.print_detail = True` 打印每只股票完整体检

## 五、抓取手法（可复用）

站点：聚宽社区帖子，正文需登录，且「源码」以**图片**形式渲染防抓取。

1. 复用本机 Edge 登录态：
   - 完全退出 Edge
   - `msedge.exe --remote-debugging-port=9222 --user-data-dir="<Edge User Data>"`
   - 检查 `http://127.0.0.1:9222/json/version`
2. 用 Node 原生 `WebSocket`（Node ≥ 22）走 CDP `Runtime.evaluate` 读 DOM
3. 帖子正文里发现嵌的**回测 iframe**：`/algorithm/backtest/summary?backtestId=...`
4. 点「源码」tab 后，代码**不在 DOM 里**（`ace_editor` 只是 CSS）；
   实际是 `<img src="https://image.joinquant.com/xxxx">`（777 × 6019 长图）
5. `curl` 直接下载该图片（无需 cookie，CDN 公开）
6. `PIL` 按 900px 切段 → 逐段读取

**教训**：
- 页面「看起来有代码」≠ DOM 里有代码。**先查 img/canvas**。
- 找代码的可靠顺序：DOM 文本 → 执行上下文 → **图片**。
