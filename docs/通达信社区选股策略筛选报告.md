# 通达信社区选股策略筛选报告

> 日期：2026-09-14
> 数据：`data/stockbars/bars_all.parquet` + `universe_all.csv`（5260 只 / 902 万行 / 2019-01-01 ~ 2026-09-11）
> 口径：复用 `tools/backtest_stock.py` 的 A 股机制（T+1 开盘成交、一字涨跌停不可成交、停牌不可成交、佣金+印花税+滑点）
> 脚本：`tools/tdx_strategies.py`（策略库+翻译层）、`tools/sweep_tdx.py`（批量回测）、`tools/diag_tdx_direction.py`（方向诊断）

---

## 0. 结论摘要

| 问题 | 结论 |
|---|---|
| 社区选股策略能直接用吗？ | **不能**。15 条全部跑输等权全池基准 |
| 按社区常见用法（持有 5 天） | **全部为负**：年化 −5.11% ~ **−36.41%**，夏普 −0.14 ~ −1.24 |
| 拉长持有期（20 天） | 大部分转正，但**仍全部跑输**。最好的二次金叉 10.63% / 夏普 0.58，输基准 4.98pp |
| 为什么失败？ | **它们几乎全是追涨型**（13/15），而 A 股 2018~2026 是**反转市** |
| 关键证据 | 「信号触发时该股过去 20 日收益分位」与年化的相关系数 **r = −0.896** |
| 有可用的吗？ | 唯二的两条**抄底型**（二次金叉、低位金叉）恰好是表现最好的两条 |

**一句话**：社区公式的问题不是"写得不好"，而是**方向与市场结构相反**——
它们教你在股票涨过之后买，而这段市场奖励的是反过来做。

## 1. 方法

### 1.1 策略来源

社区渠道（`WebSearch` 确认）：通达信官方内置公式库、**理想论坛 / MACD论坛**公式板块、
付费平台（淘宝/公众号）、CSDN / 知乎 / 百度文库的合集文章。

本次入库的策略来自知乎合集《通达信收集最好的选股公式（源码合集）》
（`zhuanlan.zhihu.com/p/643811671`），共 34 条选股公式 + 主图/副图指标若干。

### 1.2 纳入与排除

**纳入 15 条**（纯 OHLCV 可复现）：
低位金叉、二次金叉、三线粘合、四线粘合、蓄势待发、强势股四均线角度、紫色冲关、
横盘是银、枪挑小梁王、短线之王、黑马起步、起攀选股、黑马摇篮、金叉选股指标、中短波选股。

**排除 10 类**，原因逐条列明（这部分本身就是一个筛选结论）：

| 被排除的公式 | 原因 |
|---|---|
| 绝地反弹(1)(2) | 含 `BACKSET`（**未来函数**），且源码残缺、变量未定义 |
| 三线乾坤等主图指标 | 含 `BACKSET` 未来函数；且属绘图指标非选股 |
| 黄金坑 / 资金流向 / 变色MACD / 至尊MACD | 副图绘图指标，非选股；源码有截断 |
| 财务突破选股 | 用 `FINANCE()` 财务数据，本机数据无此字段 |
| 拉升在即 | 用 `INDEXA` 大盘指数与 `CAPITAL`，数据不可得 |
| HMYZ黑马易找 | 用 `COST()` 成本分布，数据不可得 |
| 黑马摇篮之小黑马 | 20 阶加权 `REF` 展开，源码在网页转换中残缺 |
| 黄转紫选股 / 聚宝盆 | 源码残缺（条件未闭合、`REF` 缺参数） |
| 次日涨停 | 用 `BARSLAST` 回溯，且与"枪挑小梁王"重复 |
| 三线粘合(2) / 紫色冲关(1)(3)(4)(5) | 与已纳入版本重复，或含 `CAPITAL` 流通盘限制 |

### 1.3 翻译偏差（**必须披露**）

`bars_all` 只有 OHLCV，社区公式常引用本机拿不到的数据。翻译时做了如下取舍，
**回测结果只在标注后的口径下成立**：

1. 含 `CAPITAL<=300000000`（流通盘限制）的 → **剔除该条件**，回测比原公式**更宽松**
2. 含 `HSL:=VOL/CAPITAL*100>2`（换手率）的 → 用 `VOL/MA(VOL,20)>1.5` 替代
3. 含 `INDEXC>0.98*REF(INDEXC,1)`（大盘过滤）的 → 剔除
4. `BARSLAST` 类回溯条件 → 用简化形式替代（见策略库 `note` 字段）
5. `DIFF<-0.1` 这类**绝对价位阈值** → 按 close 归一化为 `< -0.002`

每条策略的具体偏差记在 `tools/tdx_strategies.py` 的 `note` 字段，并随 CSV 一起落盘。

### 2.2 持有期是命门

`hold` 从 5 天拉到 20 天，年化普遍提升 **15~25pp**（如强势股四均线角度 −36.41% → −9.88%）。
说明社区公式常见的"信号出现就买、两三天就跑"用法是**最差的用法**。

但即使调到最优持有期，最好的二次金叉仍输基准 **4.98pp**、夏普低 **0.12**。

### 2.3 换手成本

持仓数 93~1675 只、交易笔数 5.8 万~43 万笔（7.7 年）。以 hold=5 的"枪挑小梁王"为例：
431,772 笔 / 持仓 530 只 → 年单边换手约 **53 倍**，仅成本就吞掉约 13%/年。

## 3. 失败原因：这批策略在**追涨**

### 3.1 方向诊断

对每条策略，计算**信号触发当日**该股票的过去 20 日收益**横截面分位**（0.5 = 市场中位）：

**13 条追涨型 / 2 条抄底型 / 0 条中性**，全体信号平均分位 **0.6058**。

### 3.2 追涨程度与收益几乎完美负相关

| 相关性 | r |
|---|---|
| 「过去20日分位」vs hold=20 年化 | **−0.896** |
| 「过去20日分位」vs hold=5 年化 | **−0.861** |
| 「过去20日分位」vs hold=20 夏普 | **−0.877** |

按追涨程度排序，年化基本单调下降：

```
低位金叉(0.377) +8.18%  →  二次金叉(0.456) +10.63%  →  四线粘合(0.537) +3.15%
→ … → 横盘是银(0.754) −5.25%  →  强势股四均线角度(0.952) −9.88%
```

**越追涨，亏得越多。** 这不是参数问题，是方向问题。

### 3.3 与既有研究的印证

本报告 `docs/个股多因子模型报告.md` 第 2 节已实测：A 股 2018~2026 是**中期反转市**，
20/60/120 日动量 IC **全为负**（−0.03 ~ −0.05）且分组严格单调递减。

而 15 条社区策略里 13 条是追涨型 → **与市场结构正面对撞**。
反过来，唯二的两条抄底型（二次金叉、低位金叉）恰好是表现最好的两条，
方向完全一致。

## 4. 结论与建议

### 4.1 对"直接用社区公式"的结论

**不建议**。理由按重要性排序：

1. **方向反了**：13/15 是追涨型，在反转市里结构性吃亏（r = −0.896）
2. **跑不赢最强基准**：即使最优参数，也输等权全池 5pp+、夏普低 0.12
3. **成本致命**：社区用法（持有 2-3 天）下换手可达 50 倍/年，成本吞掉 13%/年
4. **数据依赖缺失**：`CAPITAL`/`FINANCE`/`COST`/`DYNAINFO` 类条件本机无法复现，
   而这些恰恰是原公式里"过滤垃圾股"的部分——**剔除后回测比原公式更宽松**
5. **未来函数**：主图/副图类公式大量使用 `BACKSET`，回测虚高、实盘必崩

### 4.2 值得带走的东西

1. ~~**"追涨程度"本身是个反向指标**，可以做成一个因子……~~
   → **已验证（见 4.4）：它与 `rev20` 在秩意义上确定性等价，属冗余，本条撤回。**
2. ~~**抄底型策略值得深挖**，可尝试并入多因子模型……~~
   → **已验证（见 4.4）：无实质增量**（年化 +0.04~0.07pp、夏普 +0.01，噪音级别）。
3. **持有期必须调**：任何从社区拿来的信号，先扫 hold ∈ {5,10,20,40}，别用默认值。
   （这条是本次唯一站住的建议：5→20 天，同一批策略年化提升 15~25pp）

### 4.4 后续验证：把抄底信号因子化（2026-09-14 完成）

脚本 `tools/sweep_tdx_factor.py`。把二次金叉 / 低位金叉从**布尔条件**改为**因子**
（触发后 20 天内恒为 1 的持有掩码，与 hold=20 表现最好保持一致）。

**（1）信号偏好什么因子**

触发样本在**当日全市场**各因子上的横截面分位（0.5 = 中位）：

| 因子 | 二次金叉 | 低位金叉 |
|---|---|---|
| `rev60` | **0.6070** | **0.6009** |
| `rev120` | **0.5715** | **0.5668** |
| `vol20` | 0.5420 | 0.5450 |
| `max20` | 0.5229 | 0.5319 |
| `illiq20` | 0.5215 | 0.5203 |
| `rev20` | 0.4793 | 0.4969 |
| `rev5` | 0.4713 | 0.4740 |
| `turn20` | 0.4596 | 0.4606 |

两个信号都**明显偏好 `rev60` / `rev120` 高分组**（中期超跌股），
而对短期（`rev5`/`rev20`）接近中位。

→ **这解释了增量为什么有限**：它们携带的信息主要是 `rev60`/`rev120`，
而这两个因子模型里已经有了。

**（2）「追涨程度」是否等价于 `rev20`**

`chase20`（过去 20 日收益的横截面分位）与 `rev20` 的**线性相关只有 −0.2715**，
但这个数字有误导性：`rev20 = −ret20`，而 `chase20 = rank(ret20)`，
在**秩意义上二者确定性负相关**（`rank(−rev20) = 1 − rank(rev20)`）。
线性相关低只是"原始值 vs 分位"的量纲差异，不是独立信息。

→ **「追涨程度」= `rev20` 的分位版，没有新信息。4.2 节的建议 1 撤回。**

**（3）增量价值回测**（tilt 0.45，与基线同口径）

| 配置 | 年化 | 夏普 | 回撤 | 持仓 | vs 基线年化 | vs 基线夏普 |
|---|---|---|---|---|---|---|
| 8 因子（基线） | 12.71% | 0.82 | −22.45% | 2243 | — | — |
| + 二次金叉 | 12.75% | 0.82 | −22.11% | 2275 | +0.04pp | +0.01 |
| + 低位金叉 | 12.78% | **0.83** | −22.06% | 2268 | +0.07pp | +0.01 |
| + 两者 | 12.70% | **0.83** | **−22.02%** | 2294 | −0.02pp | +0.01 |

**结论：方向为正，但幅度在噪音级别**（年化 +0.04~0.07pp、夏普 +0.01）。
唯一略实在的改善是回撤（+0.33~0.43pp），很可能来自持仓数增加（2243 → 2294）
带来的分散度提升，而非信号本身的信息。

→ **不建议纳入模型。** 社区信号的信息已被现有 8 因子覆盖——
这反过来是对**模型完备性的一个侧面验证**。

### 4.5 流通盘限制的检验（回应 4.3 的「补 CAPITAL 数据」）

**先更正一处误读**：`CAPITAL<=300000000`（流通股本 ≤ 3 亿）是**上限**，
原公式要的是**小盘股**，不是"过滤垃圾股"。1.3 节把它当作"过滤条件被剔除"理解反了。

腾讯 `qt.gtimg.cn` 返回 88 个字段，其中 `[44]/[45]` 是流通市值/总市值（亿元），
但**只有当前值、没有历史**；用当前股本回溯会因增发/送转产生偏差。
故改用**无前视**的流动性代理：提高 `20 日均成交额` 下限（等价于排除小盘）。

三条代表性策略，hold=20：

| 策略 | 池子 3 千万（默认） | 池子 1 亿（排除小盘） | 变化 |
|---|---|---|---|
| 二次金叉 | +10.63% / 夏普 0.58 / 回撤 −34.12% | +8.15% / 0.46 / −45.14% | **变差** |
| 三线粘合 | +3.96% / 0.29 / −46.70% | −2.57% / 0.00 / −59.94% | **变差** |
| 强势股四均线角度 | −9.88% / −0.20 / −76.61% | −13.19% / −0.30 / −79.64% | **变差** |

**三条全部变差** → 这些策略的收益确实依赖小盘股。

**两条结论**：

1. 原公式的 `CAPITAL<=3亿` 方向**是对的**——剔除它会让回测**低估**原公式。
   但它救不了这些策略：即使在默认的小盘池里，15 条仍**全部跑输**。
2. 与本项目 `docs/个股多因子模型报告.md` 一致：**alpha 长在小盘/低流动性上**
   （`illiq20` 是正贡献；`tools/sweep_poolsize.py` 显示砍小票会让夏普从 0.82 掉到 0.52）。

**叠加起来看**：社区策略本质是**在小盘股上追涨**——
在最危险的地方做最危险的事。小盘股本身波动大、回撤深，再叠加追涨方向错误，
就是 §2.1 里 −63% ~ −97% 那种回撤的来源。

## 5. 局限

1. **策略池来自单一来源**（一篇知乎合集），不代表社区全貌。理想论坛等需注册的板块未覆盖。
2. **翻译存在偏差**（见 1.3），尤其剔除流通盘/大盘过滤条件后，回测口径比原公式宽松。
   原公式在真实使用中可能表现略好，但**方向性问题（追涨）不会因此改变**。
3. **只测了两个持有期**（5 / 20 天），未扫参数网格。
4. **未做样本内外切分**：本批策略全部大幅跑输，切分意义不大；若后续深挖抄底型策略，
   需补做。
5. 回测假设 `writeoff_factor=1.0`（退市按最后收盘价了结），对持有小盘股较多的策略**偏乐观**。
