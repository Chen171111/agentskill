# 个股线：「四进三出」滞回阈值检验

> 2026-09-16 ｜ 脚本：`tools/sweep_hyst.py`
> 数据：`bars_total.parquet`（无税）+ `bars_total_tax10.parquet`（10% 税后）
> 构造：`hyst` = 股息率 ≥ `entry` 买入、已持仓跌到 < `exit` 才卖（滞回），
> 在候选里取股息率前 N；`topn` = 直接取股息率前 N（基线）

## 一、缘起：`hyst` 此前**从未真正生效过**

### 1.1 证据

`results/tax10_dividend_backtest.csv` 里 `topn` 与 `hyst` 两组：
**24 个配置（3 种过滤 × 4 个 N × 2 种模式）的 8 项指标逐行完全相同，
最大绝对差 = 0.0**（年化 / 夏普 / 回撤 / 换手 / 交易笔数全部一致）。

### 1.2 机制（读代码可确认）

```python
# topn：直接取 dy 前 N
sel = dy.nlargest(N)
# hyst：先筛出「dy ≥ entry」或「已持有且 dy ≥ exit」的候选，再取前 N
cand = buy | keep
sel  = cand_dy.nlargest(N)
```

`dy` 已先被 `min_dy=0.5` 过滤。**只要「dy ≥ entry 的股票数」恒 ≥ N**，
候选集就包含了 `dy` 的前 N 名 → 与 `dy.nlargest(N)` 选出同一批
→ **滞回阈值完全没有约束力**。默认 `entry=4%` 时，实测 `N ≤ 50` 恒成立。

→ **主人引用的「聚宽四进三出」参考策略，此前从未被真正测试。**

### 1.3 ⚠️ 「阈值是否生效」的正确判据

**不能用「平均持仓 < N」判定。** 实测 `entry=8 / exit=4` 在样本外
平均持仓仍是 **19.98 ≈ N**，但年化 11.35% ≠ 基线 8.59% —— 掩码确实变了
（`keep` 把已持有的股票留在候选里，挤掉了别的）。

> ✅ **正确判据：结果与 `topn` 基线不同（掩码不同）。**
> 这正是本项目「标签必须与实现对上」那条铁律的又一个实例。

## 四、⚠️ 功劳分解：门槛效应 vs 滞回效应（关键对照）

`hyst` 的候选集是 `{dy ≥ entry} ∪ {已持有且 dy ≥ exit}`。
所以它同时做了两件事：**① 提高了个股股息率门槛；② 保留已持有的股票**。
必须把两者分开，否则会把「门槛提高」的功劳记在「滞回」头上。

**对照实验**：跑「纯门槛」`topn`（`min_dy = entry`，不做滞回）。

### 4.1 样本外（决定性）

| 配置 | 年化 | 平均持仓 | 回撤 | 相对基线 |
|---|---|---|---|---|
| `topn` 基线 | 8.59% | 19.98 | −23.55% | — |
| 纯门槛 `min_dy=8` | **9.95%** | 18.11 | −23.62% | **门槛效应 +1.36pp** |
| **`hyst 8/4`** | **11.35%** | 19.98 | −23.54% | **滞回再 +1.40pp** |

### 4.2 三个区间汇总

| 区间 | 门槛效应 | 滞回效应 | 合计 |
|---|---|---|---|
| 全区间 | +1.98 | **+0.85** | +2.83 |
| 样本内 | +1.75 | **+3.47** | +5.22 |
| **样本外** | **+1.36** | **+1.40** | **+2.76** |

### 4.3 结论修正（重要）

> ⚠️ **早先我写「改善来自滞回机制本身，不是持仓变少」—— 这句要修正。**
>
> 准确的说法是：**改善 = 门槛效应 + 滞回效应，两者量级相当（样本外 +1.36 vs +1.40）**。
> 「不是持仓变少」这一点仍然成立 —— 而且更强：
> **`hyst` 的持仓数比「纯门槛」还多**（样本外 19.98 vs 18.11；
> 样本内 18.44 vs 13.80），因为它把已持有的股票补回了候选集。
> 所以滞回**不是**通过压缩持仓赚钱，而是通过**改变"在满足门槛的股票里留谁"**。

### 4.4 ⚠️ `min_dy=9` 的「高收益」是陷阱

| 区间 | 纯门槛 `min_dy=9` | 平均持仓 | 回撤 |
|---|---|---|---|
| 全区间 | 18.29% | **6.9** | −34.22% |
| 样本内 | 21.45% | **4.6** | **−34.22%** |
| 样本外 | **14.07%** | **8.1** | −21.15% |

样本外 14.07% 看着很香，但**持仓只有 8.1 只、样本内只有 4.6 只** ——
这是**完全不同的策略**（高度集中），不是「N=20 加个门槛」。
**不能拿它当结论。**（同类：`hyst 9/x` 的持仓也塌到 5.9~17.4。）

## 五、机制解释：它避免的是「因股价上涨而被被动卖出」

股息率 = 每股分红 ÷ **股价**。所以：

> 一只股票基本面变好、股价上涨 → 股息率**被动下降** → 朴素 `top-N` 会把它**卖掉**。

这在逻辑上是荒谬的（等于"因为涨了所以卖"），但 `top-N` 就是这么做的。
`hyst` 的 `exit` 阈值把它保留下来，只要股息率还没跌破 `exit`。

**这与「滞回/缓冲带降低换手」是同一类机制**，也解释了为什么：
- 换手下降（样本外 2.93x → 2.71x）
- 收益与夏普提升，而**风险暴露不变**（持仓数、回撤几乎相同）
- 门槛效应与滞回效应量级相当（门槛筛掉价值陷阱，滞回避免被动卖出）

⚠️ **但要警惕一个反向可能**：保留"股价涨了、股息率降了"的股票，
在 A 股这种**中期反转市**（本项目实测动量 IC 全为负）里理论上应该是**减分**的。
实测却是加分 → 说明这里起作用的不是"动量"，而是**"避免被股息率这个被动指标牵着走"**。
**这条机制解释是推测，未做归因验证**，列在 §八 局限里。

## 八、必须说清的局限

1. **`entry=8` 贴着「生效边界」**（7 不生效、8 生效）。
   若未来市场股息率整体抬升，`entry=8` 可能重新失去约束力 → **改善会消失**。
   这个参数**稳健性天然打折**，需要在实盘/滚动监控里盯着「候选池大小」。
2. **`exit` 参数不单调**（`entry=8` 行：19.27 / 18.36 / 18.06 / 19.16 呈 U 型）→
   说明该参数有噪声。好在**四个值都远高于基线**，方向不依赖单点。
3. **机制解释（§五）是推测**，未做归因验证（例如：验证被"保留"的那批股票
   后续表现是否真的优于被"替换"掉的）。
4. **未与「行业中性化」叠加测试** —— 两者都改善样本外，但是否可叠加未知。
5. **未做 `N` 敏感性** —— 本文固定 `N=20`；`hyst` 在不同 `N` 下的行为未测。
6. **未测 `hold=20`（月度）** —— 月度持仓可能不足 1 个月，红利税要按 20% 档
   （见 `docs/个股线_红利税.md` §六）。
   **本文的税后结论只覆盖 `hold=60`（季度、10% 档）。**
7. **回撤在样本内变差**（−20.10% → −25.03%），这是真实代价，不是噪声。

| `hyst` + 行业配额 | 18.77 / 0.92 / −20.59 | 22.58 / 1.02 / −19.63 | 9.34 / 0.58 / −26.63 | 9.27% |

### 11.2 判定：**全区间可叠加，样本外基本不可叠加**

| 区间 | 单独增量（行业 / 滞回） | 相加 | **叠加实测** | 保留比例 |
|---|---|---|---|---|
| 全区间 | +3.20 / +2.84 | +6.04 | **+5.10** | 84% |
| **样本外** | +2.19 / +2.76 | +4.94 | **+2.84** | **58%** ⚠️ |

**样本外看细节更清楚**：

```
基线 8.59%  ──[hyst]──▶  11.35%  ──[再加行业内]──▶  11.44%   （只 +0.09pp！）
基线 8.59%  ──[行业内]──▶ 10.78%  ──[再加 hyst]──▶  11.44%   （+0.66pp）
```

→ **两者高度重叠**：任一个单独就能拿到大部分改善，**加在一起几乎不再增加**。
（这与 §四 的发现一致 —— `hyst` 的功劳里本来就有一半是「门槛」，而门槛与
「行业内选股」都在做同一件事：**在更干净的池子里挑**。）

### 11.3 但叠加**修好了 `hyst` 的回撤问题**

这是叠加最大的意外收获。`hyst` 单独的主要代价是回撤变差（全区间 −21.37% → −25.03%）；
加上行业内中性化后：

| 配置 | 全区间 年化 | 夏普 | **回撤** |
|---|---|---|---|
| `hyst 8/4` | 19.27% | 0.98 | **−25.03%** ⚠️ |
| **`hyst` + 行业内** | **21.54%** | **1.09** | **−22.67%** ✅ |
| 行业内单独 | 19.64% | 1.03 | −22.68% |

→ **年化还更高（+2.27pp）、夏普更高、回撤回到与「行业内单独」同一水平。**
样本内同样：28.13% / 1.28 / −22.67%（`hyst` 单独是 24.51% / 1.15 / −25.03%）。

**⚠️ 但样本外回撤反而更差**：−24.91%（`hyst` 单独 −23.54%、行业内单独 −20.63%）。
三段区间里只有全区间/样本内的回撤被修好。

### 11.4 `hyst` + 行业配额：**不可用**

样本外只有 9.34%，**平均持仓塌到 13.2 只**（全区间 12.1 只）——
「行业配额」和「滞回」是**双重约束**，一起上会把持仓压得太少，
已不是「N=20 组合」。**和 §三.1 的 `entry=9` 是同一类错误。**

### 11.5 结论与建议形态

| # | 结论 |
|---|---|
| 1 | **两个改进在样本外基本不可叠加**（只保留 58%）→ 高度重叠，不是两个独立 alpha |
| 2 | **但 `hyst` + 行业内是全区间/样本内的最优组合**，且**修好了 `hyst` 的回撤问题** |
| 3 | 样本外最优 N=20 配置是 `hyst`+行业内 **11.44%**（10 万真实 **11.20%**），但只比 `hyst` 单独高 0.09pp |
| 4 | ⚠️ 样本外回撤 −24.91%，是 N=20 配置里最差的 |
| 5 | ⚠️ `hyst` + 行业配额**不可用**（持仓塌陷） |

**建议形态（二选一，取决于看重什么）**：

| 选择 | 配置 | 理由 |
|---|---|---|
| **简单** | `hyst 8/4` + 全局 top-N | 样本外 11.35% ≈ 叠加的 11.44%，**少一层复杂度** |
| **稳健** | `hyst 8/4` + **行业内百分位** | 全区间 21.54% / 夏普 1.09 / 回撤 −22.67%（三项全优）；样本内 28.13% / 1.28 |

### 11.6 税后复跑（10% 档）：结论**完全一致**

| 配置 | 全区间 年化/夏普/回撤 | 样本内 | **样本外** | 样本外 10万真实 |
|---|---|---|---|---|
| 原始 `topn`（基线） | 16.08 / 0.86 / −21.51 | 19.02 / 0.95 | **8.14 / 0.52 / −23.76** | 7.84% |
| 行业内百分位 | 18.94 / 1.00 / −22.85 | 21.21 / 1.05 | 10.38 / 0.64 / −20.95 | 10.10% |
| `hyst 8/4` | 18.73 / 0.96 / −25.07 | 23.86 / 1.12 | 10.89 / 0.65 / −23.76 | 10.62% |
| **`hyst` + 行业内** | **21.32 / 1.08 / −22.78** | **28.24 / 1.28 / −22.78** | **10.98 / 0.66 / −25.49** | **10.74%** |
| `hyst` + 行业配额 | 18.31 / 0.90 / −21.11 | 22.11 / 1.00 | 8.88 / 0.56 / −26.95 | 8.81% |

| 判定 | 无税 | **税后** |
|---|---|---|
| 全区间叠加保留比例 | 84% | **95%** |
| **样本外叠加保留比例** | 58% | **57%** |
| 税成本（`hyst`+行业内） | — | 全区间 −0.22pp、样本外 **−0.46pp** |

→ **三条结论（§11.5）在税后一条都不变**：样本外不可叠加、全区间三项全优、
`hyst`+行业配额不可用。**红利税只是把水平整体下移约 0.46pp。**

**税后最优落地数字（样本外、10 万真实年化）**：

| 配置 | 10 万真实（税后） |
|---|---|
| 原始 `topn`（基线） | 7.84% |
| 行业内百分位 | 10.10% |
| `hyst 8/4` | 10.62% |
| **`hyst` + 行业内** | **10.74%** ← 最高 |
| `hyst` + 行业配额 | 8.81%（不可用） |

> ⚠️ 另有一个数字更高：**行业配额中性 `N=50` 样本外 12.24% / 10 万真实 11.18%**。
> 但 **`N=50` 已多次被证明不稳健**（样本内最优 50、样本外最优 10），
> 且它全区间只有 16.47%（远低于 `hyst`+行业内的 21.32%）→ **不推荐**。
