# 同花顺经典版（模拟炒股）接入配置指南

本文档是 agentskill 接入「同花顺经典版·模拟炒股」的完整操作步骤，从零到跑通。

> 适用范围：Windows + 同花顺**经典版**（网上交易版/免费版），非远航版、非极速版。
> 已验证：本机已装有经典版 `D:\同花顺软件\同花顺\xiadan.exe`，可直接复用。

---

## 一、前置检查

### 1.1 确认本机已有经典版

在资源管理器地址栏输入以下路径，看 `xiadan.exe` 是否存在：

```
D:\同花顺软件\同花顺\xiadan.exe
```

- ✅ 存在 → 直接跳到「二、安装依赖」
- ❌ 不存在 → 到 [同花顺官网](https://www.10jqka.com.cn/) 下载「同花顺免费版（网上交易）」安装

> 注意：**远航版、极速版不能用**。远航版是另一套内嵌交易机制，easytrader 无法操控。本项目针对的是经典版独立委托程序 `xiadan.exe`。

### 1.2 确认 Python 环境

```bash
python --version   # 需 3.7+
```

---

## 二、安装依赖（关键）

### 2.1 手动安装 easytrader

> ⚠️ 在 TraeCode 沙盒内 `pip install easytrader` 会被权限拦截（无法写入系统 site-packages）。
> 请**在系统 PowerShell / CMD 手动执行**（管理员权限更稳）：

```powershell
pip install easytrader
```

安装包含 `pywinauto`、`flask` 等依赖，用于操控同花顺窗口。

### 2.2 验证安装

```powershell
python -c "import easytrader; print(easytrader.__version__)"
```

无报错即成功。

---

## 三、配置同花顺客户端（一次性）

1. 双击 `xiadan.exe` 启动，用同花顺账号登录；
2. 进入「交易」界面，选择**「模拟炒股」**（证券公司下拉里选"模拟炒股"，资金账号=手机号，密码=同花顺登录密码）；
3. 关键设置（否则 easytrader 控制会失败）：

   | 位置 | 设置项 | 值 |
   |---|---|---|
   | 系统设置 > 界面设置 | 界面不操作超时时间 | **0** |
   | 系统设置 > 交易设置 | 默认买入价格/数量 | **空** |
   | 系统设置 > 交易设置 | 默认卖出价格/数量 | **空** |

4. **不要最小化**窗口，**不要使用精简模式**；
5. 客户端保持在"模拟炒股"的交易界面（买卖委托窗口）。

---

## 四、运行 agentskill 接同花顺

### 4.1 先跑一次本地模拟（确认策略/数据正常，不下单到同花顺）

```powershell
cd E:\MyWorkAndProject\量化\agentskill
python main.py run --strategy momentum --pool 个股动量
```

### 4.2 接入同花顺模拟炒股下单

```powershell
python main.py run --strategy momentum --pool 个股动量 --ths --ths-exe "D:\同花顺软件\同花顺\xiadan.exe"
```

### 4.3 每日定时自动运行（常驻，交易日 15:05 触发）

```powershell
python main.py daemon --strategy momentum --pool 个股动量 --ths --ths-exe "D:\同花顺软件\同花顺\xiadan.exe"
```

---

## 五、参数说明

| 参数 | 说明 |
|---|---|
| `--ths` | 启用同花顺下单（不传则用本地 PaperBroker 模拟撮合） |
| `--ths-exe` | 同花顺委托程序 `xiadan.exe` 的完整路径 |
| `--strategy` | 策略名：momentum / mean_reversion / cross_moving / multifactor / lianban_lead |
| `--pool 个股动量` | 沪深300 抽样 20 只个股池（模拟盘必须用个股，指数不可交易） |
| `--topk` / `--rebalance` | 持仓数 / 调仓周期 |

---

## 六、常见问题

| 问题 | 原因 | 解决 |
|---|---|---|
| `RuntimeError: ThsBroker 未连接` | 没传 `--ths-exe` 或连接失败 | 检查 xiadan.exe 路径、客户端是否已登录交易窗口 |
| 下单价格/数量错误 | 客户端"默认买卖价格/数量"没清空 | 按第三节第3步设置 |
| 客户端超时锁定 | 超时时间不是 0 | 设 0 |
| 找不到窗口 | 窗口最小化/精简模式 | 保持窗口正常打开 |
| 模拟炒股资金不符 | 平台 INIT_CASH=100万，与同花顺可能不同 | 实际下单金额按账户可用资金为准 |

---

## 七、重要提示

1. **同花顺模式依赖桌面环境**：`daemon` 常驻运行时电脑不能锁屏/睡眠，客户端必须一直开着。适合本地个人使用，不适合无头服务器。
2. **成交价以同花顺回报为准**：ThsBroker 按限价委托下单，实际成交价/数量以客户端委托回报为准。
3. **委托 ≠ 成交**：限价单可能不成交，`submit()` 返回 `filled` 仅表示"委托已提交成功"，真实成交需查 `today_trades`。
4. 若追求更稳定、可远程的自动化，建议后续考虑券商官方 QMT/Ptrade 接口。
