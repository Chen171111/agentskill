从本地20份缓存读取并重跑9组，20/20输入指纹保持不变；逐日观察12696次虚拟账户现金，均非负，净值输出均有限。默认ETF全球策略在原README区间累计 **35.038941%**、年化 **4.010517%**、最大回撤 **−8.148340%**、夏普 **0.614024**；同期基准累计51.773285%，累计超额 **−16.734344个百分点**。

README的主表与多周期比较表已同步；旧28.28%等数字保留在明确标记的历史修复记录中，不再代表当前代码。九组的实际起止日及全部指标见JSON；上市较晚的池不能按请求日期冒称拥有更早历史。

精确公司行为可通过缓存的 `split_ratio` 提供“新份额/旧份额”比例；未提供时继续使用已有跳变判据推断，并标记 `split_inferred`。价格跳变无法同时识别精确折算比例与当天真实涨跌，推断模式仍是近似。`raw_*` 保留的是缓存来源价格；若来源本身已复权，它不会凭空恢复交易所历史原价。前缀因果性和精确比例路径已有行为测试，这些测试不消除数据来源本身的限制。

当前OCR市值交叉核验仍沿用既有2%/5%容差，小于容差的漏读存在漏检可能；本次没有把容差测试通过写成“任意OCR错误均能识别”。真实客户端版本差异、实际委托回执和在线成交需由真实运行记录继续验证。
