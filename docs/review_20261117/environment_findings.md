## E01 · P1 · 失败退出码在批处理和 conhost 两层丢失

位置：`daily_run.bat:64`—`:65`；实际任务动作见 tasks_snapshot.json。

隔离目录复制原始 daily_run.bat，三个 Python 入口替换成只写合成标记的短脚本。下单短脚本返回 7 后：

| 调用方式 | 结果 |
|---|---:|
| 普通 `cmd /c exit 7`（正对照） | 7 |
| 原始 daily_run.bat，日志写 `[done] exit=7` | **0** |
| `conhost --headless cmd /c exit 7` | **0** |
| conhost 包装原始 daily_run.bat | **0** |

这是当前“调度器显示成功、业务实际失败”的可复现解释。既要在批处理中保存并显式传递退出码，也要替换或验证上层包装方式；只修其中一层仍不够。没有修改实际任务。

## E02 · P1 · 下单确认缺失字段时放行，方向和限价没有充分校验

位置：`trader/ths_uia.py:492`—`:513`；`trader/ths_parse.py:42`—`:66`。

原方法的行为已用模拟弹窗复现：

- 数量明确不一致会拒绝（正对照），但**数量字段完全缺失反而确认**。
- Order 为买入，弹窗正文为卖出，仍确认。
- 显式限价模式预期价格 10，弹窗价格 100，仍确认并把本地价格改成 100。
- 解析出的证券代码是 510500，只要正文其他位置含预期代码 510300，全文子串检查仍会通过。

修复应要求关键字段全部可解析、证券代码精确相等、方向一致、数量一致、价格有限且符合定价模式；关键字段缺失应拒绝。所有“点击”都是测试替身，没有接触真实界面。

## E03 · P1 · 缺少券商订单唯一身份，成交回读可能关联旧单

位置：`trader/ths_parse.py:515`—`:525`；`trader/ths_uia.py:638`—`:672`、`:1320`。

两条同日、同代码、同方向、同数量的合成委托：旧单已成交、新单未成交。旧单排第一时，新订单被回填为已成交，价格也取旧单；只把列表顺序调换，就变成未成交。这不是数量字段解析问题，而是缺少唯一关联依据。

另一个复现场景中，提交确认之后没有读到成功回执，方法仍标记 submitted；订单对象没有保存券商合同编号。当前本地随机 ID 不能代替券商合同号。

修复方向：提交后读取并持久化券商订单号；回填优先按唯一编号匹配。无法唯一关联的多行应保持未知，不能任取第一行；无法确认回执时也应明确记录“提交结果未知”。

## E04 · P2 · 已撤/废单的终态被写回为已报

位置：`trader/ths_parse.py:441`—`:450`；`trader/ths_uia.py:1343`。

解析层把已撤、废单映射为“已撤”；sync_fill 随后只区分“已成”和其他，**已撤被改写为 submitted**。合成撤单行已复现这一结果。会影响未决委托核对与后续重试决策。

修复应保留撤单、拒绝、部分成交、成交未知等状态，并对历史未决订单设置独立的更新/对账流程。

## E05 · P1 · 收盘后首次启动仍能进入下单链路

位置：`tools/daily_job.py:184`、`:263`—`:278`。

重试有截止时间，但第一次执行之前没有交易时段守卫。把合成时间设为 19:00，预检就绪后，交易子进程仍被调用 1 次，尽管 `_in_retry_window()` 已经为 False。

这与任务 `StartWhenAvailable=true`、手动补跑入口叠加，会使迟到启动继续走真实交易程序。本次只证明“进入链路”，没有声称收盘后一定成交。修复应在执行前检查时段；所有手动/自动入口复用同一规则。

## E06 · P2 · 睡眠后没有重查时间，重试可以跨过截止点

位置：`tools/daily_job.py:288`—`:295`。

合成第一次失败在 **14:55:50**，检查当时早于 14:56，然后睡眠 120 秒；第二次尝试在 **14:57:50** 照常执行。应按绝对截止时刻限制等待，并在每次尝试前重新核验。

## E07 · P1 · 数据体检失败后，批处理仍继续启动交易

位置：`daily_run.bat:39`—`:40`、`:64`。

合成刷新入口返回健康检查失败码 **3**，批处理仅写 WARN，随后仍调用交易入口。现有新鲜度守卫只负责日期等校验，不能代替整项数据体检结果。

修复应让数据健康检查成为交易前置条件；若要区分可容忍的下载失败与不可容忍的数据损坏，应使用结构化结果明确区分。本次并未认定当前 11 只缓存存在损坏。
