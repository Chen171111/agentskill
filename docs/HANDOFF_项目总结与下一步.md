## 零、⚠️ 先纠正一个我说过的错误说法

**我曾说「个股多因子实盘需 2,243 只持仓、门槛 2,243 万」。这个说法不严谨，必须纠正。**

| 事实 | 说明 |
|---|---|
| 2,243 只是**我的 `tilt` 研究构造**的持仓数 | `tilt` 模式 = 全池按分数倾斜加权，凡是 score>0.45 的全部持有 |
| **它不是个股多因子的普遍要求** | 真实个股策略通常只持 **10~50 只** |
| 主人举的反例成立 | 聚宽「四进三出」高股息策略（股息率 >4% 买、<3% 卖）**只持少数几只** |

**为什么我的模型需要广度、而高股息策略不需要？**

| | 我的因子集 | 高股息策略 |
|---|---|---|
| 信号类型 | **弱信号**（IC 仅 0.05~0.07） | **强信号**（股息率是真实、持续的价值信号） |
| 衰减速度 | **快**（5 日调仓，年单边换手 9.5 倍） | **慢**（阈值触发，可能几个月不动） |
| 收益来源 | `IR ≈ IC × √breadth` → **靠 2200 次独立下注累积** | 靠**少数几次高置信度下注** |
| 需要的持仓数 | 2000+ | 10~30 |
| 10 万下资金门槛 | 2,243 万 | **10~30 万**（可行） |

→ **正确的结论不是「10 万做不了个股」，而是「10 万做不了'弱信号 × 高换手'这一类的个股策略」。**
→ **正确的下一步不是「攒钱」，而是「换因子类型」。**

> ✅ **2026-09-15 晚已验证，并且要再修正一次措辞**：
