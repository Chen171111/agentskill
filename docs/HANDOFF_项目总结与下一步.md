## 一、项目背景与目标

### 1.1 要做什么

把 A 股交易的 **「信号 → 风控 → 下单」全链路自动化**，并在**真实资金量级**下验证策略能否落地。
不是做研报，是做一个**能长期无人值守跑、且结论可复现**的系统。

### 1.2 两条线

| 线 | 状态 | 说明 |
|---|---|---|
| **ETF 轮动线** | ✅ **实盘在跑**（同花顺模拟盘，工作日 14:50 计划任务） | 池 `ETF全球` / `etf_rotation` / topk=5 / 5 日调仓 |
| **个股线·股息率** | 🟡 研究定稿 + **纸面跟踪中**，未上实盘 | 全A池 →（0.5%≤dy≤10% + 近3年分红≥2次）→ **行业内百分位** → N=20 等权 → hold=60 交易日 |

另有 **4 条已证伪路线**（个股多因子 / 短线个股 / 通达信社区公式 / 精灵大单），结论已归档，**不要再走**。

### 1.3 硬约束（决定了整个技术选型）

> 📌 **资金口径声明**（2026-09-19 主人拍板）
>
> 本文与**本仓库全部文档**中出现的「**10 万**」，一律指 **策略建模块化的资金档位** ——
> 它服务于**最低佣金惩罚建模**（10 万 ÷ 20 只 = 5,000 元/笔 → **有效佣金率其实是万10**，
> 见下表第 2 行）；`config.py` 的 `INIT_CASH = 100_000.0` 是同一个**回测口径常量**。
>
> **它不是账户余额、不是账号、也不是可识别个人身份的财务细节** ——
> 账户类信息（余额 / 持仓数量 / 委托合同号 / 邮箱）已从本仓库剥离（见 §七）。
> 之所以**保留该档位数字**：佣金门槛效应**只有在具体资金量级下才能量化**，
> 换成「小资金」这类模糊措辞会让整条研究结论**失去可复现性**。
> → 决策记录见 §4.6 第 7 项；事实基线见 §5.1 第 18 条。

| 约束 | 影响 |
|---|---|
| **真实资金 10 万**（**建模档位**，非账户余额 —— 见上方口径声明） | 持仓数不能大（最低佣金惩罚）；`IR ≈ IC×√breadth` → 弱信号×高换手类策略**天生不可落地** |
| **佣金万5 / 单笔最低 5 元** | 10 万÷20 只 = 5,000 元/笔 → **有效佣金率其实是万10**（最低佣金规则的必然，**不是费率超预算**） |
| **公开仓库** | **禁止**写入账户金额、持仓数量、账号、邮箱；推送前必须扫敏感信息 |
| **机器有死机史** | 长任务必须**增量落盘 + 断点续跑** |
| **宿主会杀长任务** | 前台命令 **≈12 分钟处被 SIGTERM**；后台任务在**回合结束时被杀** → 只能「后台启动 + 同回合轮询保活」或分块 |
| **研究环境无 scipy/sklearn** | 不能用 `pandas.corr('spearman')`（会转调 scipy）→ 用 `tools/stats_lite.py` |
| **策略结论口径变更需报备** | 改因子定义 / 复权 / 税率 / 成本假设 → **先报备，不擅自替换既有结论** |

|---|---|---|
| 1 | **宿主杀长任务**：前台 ≈12 分钟 SIGTERM；后台回合结束被杀 | 「后台启动 + 同回合轮询保活」或分块；用 `run_reruns.py` 断点续跑 |
| 2 | **禁止 `\| head` 截长任务输出** | SIGPIPE 会杀进程、日志截断且无 Traceback |
| 3 | **写文件用 `open(p,"wb")`** | Windows 文本模式会把 LF 变 CRLF，污染 git |
| 4 | **`import` 失败先查 `sys.path`** | 沙箱 shim 会改 `sys.path` → 伪装成"依赖缺失" |
| 5 | **主键格式不对齐会伪装成"数据源没覆盖"** | 东财返回 6 位码 vs 本项目带前缀 → 看到 0% 命中先查主键 |
| 6 | **`pandas.corr('spearman')` 会转调 scipy** | venv 无 scipy → 用 `tools/stats_lite.spearman` |
| 7 | 沙箱里 `schtasks.exe` 被安全策略拦截 | 计划任务状态只能靠 `state/last_run.json` 间接验证 |
| 8 | Bash 工具需先修 PATH | `export PATH="/c/Windows/System32:/c/Windows:/usr/bin:/bin:$PATH"` |
