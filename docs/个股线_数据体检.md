## 一、为什么个股线必须补这一课

ETF 线出过一次很难看的事故：`data/stocks/*.csv` 是**不复权**行情，
4 处份额拆分被引擎当成真实涨跌（最夸张的 **+248.6% / −80.5%**），
污染了当时**全部** ETF 回测，还让波动率风控被虚假触发、把仓位压到 0.08 持续 20 天。
修完数据后实盘配置年化 **+0.98pp**（2.49% → 3.47%）。

个股线用的是**另一份数据**（腾讯 `fqkline` 的 `qfq` 前复权），
在本次体检之前**从未做过同等检查**。而这条线的结论（年化 16.31%、夏普 0.74）
已经写进了三份文档 —— 如果地基有问题，那三份文档全部要重写。

所以先查。**结论：个股线地基干净，不存在 ETF 线那种缺陷。**

## 二、判据：为什么这些检查能查出问题

A 股**有涨跌停**（主板 ±10%、创业板/科创板 ±20%、ST ±5%、北交所 ±30%）。
这条制度约束给了我们一个**极强的判据**：

> 任何 `|日收益|` 超过当日涨跌停幅度的行，**都不可能来自正常交易**。

它只可能是两种情况之一：

| 情况 | 说明 | 是否数据错误 |
|---|---|---|
| ① 真实的无涨跌幅限制场景 | 长期停牌**复牌首日**、恢复上市首日、新股首日 | ❌ 不是，是真实行情 |
| ② 复权口径产物 | 前复权价 = 真实价 − 累计分红，累计分红逼近真实价时**分母趋零**，收益率爆炸 | ❌ 不是"错"，是**口径的必然产物** |

关键设计：**必须先区分①②，再下结论**。把②当"数据错误"会误报，
把①当"错误"会误删真实行情。区分手段是**拉不复权数据对照**
（`--bfq-sample` / `--bfq-verify`，联网）。

## 三、体检结果（六项）

### 【1】不可能收益：15,975 行，但**没有一行是"错"的**

| 项 | 数量 |
|---|---|
| `|日收益|` > 涨跌停 + 2%（已排除上市前 5 日） | **15,975 行 / 1,119 只**（占全表 **0.177%**） |
| ① 判为「长期停牌复牌首日」（间隔 ≥20 交易日） | **102 行** |
| ② 疑似「复权口径产物」 | **15,873 行** |
| 其中落在**股票池内** | 6,210 行 / 827 只 |

> ⚠️ **我第一版结论是错的**。当时我把这 15,873 行统称为"未解释"，
> 隐含假设是"大概都是复牌"。实测只有 **102 行**是复牌 —— 少了两个数量级。
> 这个纠正来自把"我猜的"换成"我查的"（见【5】）。

典型行（按 |前复权收益| 降序）：

| 股票 | 现象 |
|---|---|
| SZ000670 盈方微 2022-08-22 | 前复权 **+488%**，间隔 **590 个交易日** → **真实复牌首日**（无涨跌幅限制） |
| SH600039 四川路桥、SH601699 潞安环能、SZ000408 藏格矿业… | 前复权收益 46~136 倍，**不复权收益仅 ±10%** → **复权口径产物** |

### 【2】非正价格：都在池外（关键）

| 项 | 行数 | 股票数 |
|---|---|---|
| `close <= 0` | 4,416 | 24 |
| `open <= 0` | 4,447 | 27 |
| `amt < 0` | 4,410 | 24 |
| `amt == 0` | 6 | 1 |
| **落进股票池的 `close<=0`** | **0** ✅ | — |
| **落进股票池的 `amt<=0`** | **0** ✅ | — |

涉及 24 只**全是高分红老股**：中远海控、兖矿能源、冀中能源、陕西煤业、潞安环能、
平煤股份、山煤国际、广汇能源、四川路桥、永兴材料…… 累计分红超过当年真实股价，
减法口径把历史前复权价压到 ≤0。

**为什么池子是干净的**：股票池要求 `close >= 2.0`（`--min-price`）。
池内 `close` 最小值 = **2.0000**，正好卡在门槛上 —— **门槛把病态行全挡住了。**
这是本次体检**最重要的一条**。

### 【3】因子层污染：655 万行里只有 **1 个** inf

在**真正的股票池内**（剔 ST + `listed≥120` + `amt_ma20≥3e7` + `close≥2.0` + 非停牌）
统计 8 个因子的 `inf` / `NaN`：

| 因子 | inf | NaN | 总行 |
|---|---|---|---|
| `rev5` | 0 | 0 | 6,552,602 |
| `rev20` | 0 | 0 | 6,552,602 |
| `rev60` | 0 | 0 | 6,552,602 |
| `rev120` | **1** | 1,560 | 6,552,602 |
| `vol20` | 0 | 0 | 6,552,602 |
| `max20` | 0 | 0 | 6,552,602 |
| `turn20` | 0 | 0 | 6,552,602 |
| `illiq20` | 0 | 0 | 6,552,602 |

- **1 个 inf**（`rev120`）占 6,552,602 行的 **0.000015%**，可忽略。
- **1,560 个 NaN** 全是**暖机期**：`rev120` 需要 121 根 K 线，
  而 `listed >= 120` 只保证 120 根 → 每只股票"入池首日"恰好缺 1 个值。
  共 1,560 只股票属于这种情况。**是设计使然，不是数据缺陷。**

> ⚠️ **这里也修过一个自己的 bug**：脚本初版打印"【3】因子层污染（池内）"，
> 但实现**根本没做池子过滤**，统计的是全表 → 得到 4~6 个 inf。
> 补上真实过滤后降到 1 个。**标签和实现对不上，比数字错更危险** ——
> 因为没人会去质疑一个"看起来对"的标签。

### 【4】前复权 vs 不复权：价格门槛有偏，但影响 0.00%

随机抽样 **40 只池内股票**（`random_state=7`），逐日对比前复权价与不复权价：

| 指标 | 值 |
|---|---|
| 前复权 / 不复权 **价格比 中位** | **0.980** |
| 价格比 **首日** 中位 | 0.828 |
| 价格比 均值 | 0.902（**左偏**：少数高分红老股拉低） |
| 样本行数 | 68,464 |
| **被 `close>=2.0` 错杀的行**（真实价 ≥2 但前复权价 <2） | **1 行 / 68,464 = 0.00%** |

**偏差是真的**：池子的 `min_price` / `min_amount` 是拿**前复权价**比出来的，
而前复权价系统性低于真实价（中位 2%），故理论上会**多剔掉**一些股票。

**但幅度可以忽略**：随机样本上错杀率 **0.00%**。

> ⚠️ **一个必须说明的自我纠正**：我第一版抽样是**刻意抽的**
> （24 只负价 + 40 只低价 + 20 只随机），算出首日比中位 0.645、错杀率 13.89%，
> 看着很吓人。**那个数字不能代表总体** —— 它是"专门挑最惨的看"。
> 换成纯随机抽样后是 0.980 / 0.00%。**报告里只能用随机数。**

### 【5】用不复权数据核实：99.98% 确认为「复权口径产物」

对"疑似复权产物"里最集中的 **25 只股票 / 6,311 行**，拉不复权数据算真实收益：

| 项 | 数量 |
|---|---|
| 核实行数 | 6,311 |
| **真实收益仍在涨跌停内** → **确认为复权口径产物** | **6,310（99.98%）** |
| 真实收益也超限 → **才是真·数据错误** | **1** |
| 前复权最大 `|收益|` | **inf** |
| 真实最大 `|收益|` | **0.200**（正好是创业板涨跌停） |

**这是整个体检最有力的一步**：同一批行，前复权口径下收益是 inf，
不复权口径下最大只有 20.0%。**问题 100% 出在复权口径，不在原始行情。**

### 【6】顺带发现：ST 过滤其实是 **no-op**（不是 bug，但要说清）

跑截断对照时引擎打印：

```
剔除 ST/退市 245 只：5260 -> 5260 只
```

**前后数字一样** —— 读者会以为过滤生效了。真相是：

| 项 | 值 |
|---|---|
| `universe_all.csv` 标 `is_st=True` | 245 只 |
| **其中出现在 `bars_all.parquet` 里的** | **0 只** |
| `bars_all` 代码数 | 5,260 |
| `universe_all` 代码数 | 5,570（差 310 = 245 个 ST + 65 个其他） |

即 **`bars_all` 里本就不含 ST/退市股**（它们被抓到 `bars_delisted.parquet` 单独存放），
所以引擎那句过滤是**空操作**。

**这不是缺陷** —— 效果与"过滤生效"完全等价（池子里就是没有 ST）。
但它属于方法论铁律第 5 条说的那类问题：**"跳过/no-op"必须被说出来，不能静默**。
已在 `tools/backtest_stock.py` 与 `tools/diag_stock_ret_clip.py` 改成显式提示：

```
ST/退市名单 245 只均不在数据中（bars 已不含 ST）→ 过滤为 no-op：5260 只
```

（ST 相关的**前视偏差**早已单独量化结案：`docs/个股多因子模型报告.md` §8.7，≤0.25pp。）

## 四、涨跌停截断对照：极端值**不影响**策略

前三项说的是"病态行没进池子"，但还有一个隐患没排除：
**复权口径在接近 0 时的放大效应是渐进的**，不只有"分母为 0"那一瞬间。
即池内那些没被涨跌停判据抓到的行，收益也可能被系统性放大。

做法（`tools/diag_stock_ret_clip.py`）：把 `|ret1|` 截断到当日涨跌停 **+2%**
（与体检判据一致，避免误伤四舍五入导致的合法涨停日）、
**重建一条干净的合成价格路径**（`close_syn = 首日收盘 × cumprod(1+ret1_clip)`，
未触发的行完全不变），用干净路径重算全部 8 个因子，再跑同一个回测。

**截断命中 15,975 行 / 1,119 只 = 全表 0.1771%** —— 与体检【1】的数字**完全对上**
（这一步本身就是交叉验证：两条独立路径数出了同一个集合）。

| 配置 | 数据 | 年化 | 夏普 | 最大回撤 | 累计 |
|---|---|---|---|---|---|
| `topk=800` | 原始 | 16.31% | 0.74 | −35.40% | 217.94% |
| `topk=800` | **截断** | **16.38%** | **0.74** | −35.58% | 219.51% |
| `topk=1200` | 原始 | 16.89% | 0.78 | −33.71% | 230.36% |
| `topk=1200` | **截断** | **16.80%** | **0.78** | −33.83% | 228.35% |

| 配置 | Δ年化 | Δ夏普 | Δ回撤 |
|---|---|---|---|
| `topk=800` | **+0.07pp** | **0.00** | −0.19pp |
| `topk=1200` | **−0.09pp** | **0.00** | −0.12pp |

**怎么读这个结果**：

1. **原始组精确复现了 16.31% / 0.74**（引擎的已知结果）→ 脚本接线正确，
   差异确实只来自"截断"这一个改动。
2. **Δ 只有 ±0.1pp、夏普完全不变。**
3. **最关键的一条：Δ 的符号在两个配置间翻转**（800 是 +0.07、1200 是 −0.09）。
   如果极端收益在**虚增**策略收益，截断后应该**系统性下降**；
   符号随机翻转说明这**纯粹是噪声**，不是被抹掉的 alpha。

→ **就"被判据抓到的那 15,975 行"而言，抹平它们对策略结论没有影响。**
但**这不等于"复权口径没问题"** —— 见下方的重要更正。

> ### ⚠️ 重要更正（2026-09-15 晚补）：截断对照**低估了约 10 倍**
>
> 后来在做「分红数据可得性」时顺手拿**不复权价**对照，发现腾讯的 `qfq` 是**仿射复权**
> （`bfq = k·qfq + m`），**不保持日收益** —— 中国神华 2019-01-04
> 真实 **+2.15%**，qfq 口径算出 **+17.92%**（8.3 倍）。
>
> **而放大是渐进的**：真实涨 0.5% 的股票放大 8 倍后是 4.2%，
> **远在涨跌停之内，本节的判据根本抓不到它**，但它的 `revN`/`vol20`/`max20` 全被放大 8 倍。
> 池内 6,730,339 行里，放大倍数 **>1.05 的占 28.2%、>1.10 的占 14.9%**。
>
> **用"重建数据"重测的真实影响**：`topk=800` 年化 **−0.89pp**、`topk=1200` **−0.97pp**
> —— 比本节截断法测出的 −0.05 / −0.07pp **低估了约 10 倍**。
>
> **教训：渐进式偏差必须用"重建数据"来测，不能用"打补丁式截断"来测。**
> 详见 **`docs/个股线_复权口径缺陷.md`**。
>
> （好消息：修正后策略仍然成立 —— `topk=800` 年化 **15.83%**、夏普 **0.74**，
> 8 个因子 IC 全部存活。所以本节"病态行没进池子"的结论**本身是对的**，
> 只是**不足以**支撑"复权口径无影响"。）

> ⚠️ 这个脚本我写错过两次，都值得记下来（见 `SKILL.md` 坑 18）：
> ① 阈值一开始取 `|ret1| > limit`，把 **14 万行合法涨停日**（涨跌停价四舍五入到分，
> 实际收益可略超名义幅度）也一起抹了，截断比例虚高到 1.55%；
> ② 修完阈值后 `where` 的掩码又写反了 ——
> `Series.where(cond, other)` 是"**cond 为 True 处保留原值**"，
> 我写成 `raw.where(hit, clipped)` → **异常行原封不动、正常行被替换**（而正常行的 clip 是恒等），
> **等于什么都没做**，却照样输出了一份"看起来合理"的对照（Δ −0.05pp）。
> **教训：数据变换必须有一条"变换后差异行数 = 预期行数"的断言。**
> 这里的断言就是"截断 15,975 行 = 体检【1】的 15,975 行"，它一眼就暴露了问题。
