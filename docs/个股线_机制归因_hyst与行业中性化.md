# 个股线：机制归因 —— `hyst` 与「行业内选股」到底共享了什么

> 2026-09-16 ｜ 脚本：`tools/diag_industry_hyst_overlap.py`（新增）
> 数据：`bars_total_tax10.parquet`（税后 10%）+ `industry_all.parquet`
> 配置：`N=20` / `hold=60` / `≤10%` + `≥2次`，逐调仓日对比

---

## 一、为什么做这个

`docs/个股线_股息率实盘方案.md` 发现一个矛盾：

| 改进 | 样本外增量（4 个 hold 均值） | 一致为正？ |
|---|---|---|
| 行业内百分位 | **+5.00pp** | ✅ 4/4 |
| `hyst 8/4` | **+1.92pp** | ✅ 4/4 |
| **两者叠加** | **−0.64pp**（相对行业内） | ❌ 2/4 |

**两个各自都有效的改进，叠加起来互相抵消。** 只有两种可能：

1. 它们选出的股票**高度重叠**（在做同一件事）；
2. 它们各自的收益**在不同区间反号**（偶然）。

本脚本回答①。三个待验假设：

| # | 假设 | 结论 |
|---|---|---|
| H1 | `indpct` 隐含地**提高了股息率门槛** | ❌ **证伪**（见第四节） |
| H2 | `hyst` 与 `indpct` **选出大部分相同的股票** | ❌ **证伪**（J ≈ 0.29） |
| H3 | 两者都在**压缩行业集中度 / 候选池** | ✅ **半对**：`indpct` 在压缩，`hyst` **没有**（见第二节） |

## 二、核心发现：**共享机制是「行业暴露方向相反」**

### 2.1 四种构造的画像（样本外 2023~2026，15 个调仓日）

| 构造 | dy均值% | dy最低% | dy<8%占比 | **行业数** | **行业HHI** | **行业dy暴露** |
|---|---|---|---|---|---|---|
| 原始 `topn` | 8.85 | 8.19 | 13.0 | 12.3 | 0.107 | 2.73 |
| **行业内百分位** | 7.43 | 2.18 | 50.7 | **20.0** | **0.050** | **2.42** |
| **`hyst 8/4`** | 8.61 | 7.42 | 13.0 | **12.3** | **0.109** | **2.72** |
| `hyst`+行业内 | 8.18 | 5.00 | 26.3 | 17.5 | 0.063 | 2.58 |

> `行业dy暴露` = Σ(行业权重 × 该行业在合格池里的平均股息率)。
> **越大 = 组合越集中在"高股息行业"**（煤炭/银行/钢铁/房地产那一类），
> 也就是**行业 beta 暴露越高**。这是本脚本为回答"两者是否在同一个维度上用力"而新加的指标。

### 2.2 读法（三句话）

1. **`indpct` 的收益来源是「行业分散」**：行业数 12.3 → **20.0**、
   HHI **0.107 → 0.050（腰斩）**、行业 dy 暴露 **2.73 → 2.42（下降）**。
2. **`hyst` 完全不改善行业暴露**：12.3 / 0.109 / 2.72 ——
   **与原始 `topn` 的 12.3 / 0.107 / 2.73 几乎一模一样**。
   它的收益来自别处（高门槛 + 保留已持有股票），**代价是行业重新集中**。
3. **叠加时两者打架**：`hyst`+行业内 的行业数只到 **17.5**（不是 20.0）、
   HHI **0.063**（不是 0.050）、暴露 **2.58**（不是 2.42）
   → **`hyst` 的 8% 高门槛天然偏向高股息行业，把 `indpct` 刚建立的行业分散吃掉了一部分。**

> **→ 共享机制不是"选同一批股票"，而是"在同一个约束维度（行业暴露）上方向相反"。**
> 一个在降低行业 beta，另一个在（无意中）把行业 beta 拉回来 →
> **叠加必然互相抵消。** 这也与 `docs/个股线_行业中性化.md` 的结论自洽：
> 行业配置超额三段全为负（−1.69 / −0.03 / −4.54）→ **往高股息行业集中是负贡献**。

### 2.3 三个区间的画像一致性

| 区间 | 构造 | 行业数 | 行业HHI | 行业dy暴露 |
|---|---|---|---|---|
| 全区间（31 期） | `indpct` | 20.0 | 0.050 | 2.41 |
| | `hyst` | 12.2 | 0.109 | 2.75 |
| | 叠加 | 16.1 | 0.072 | 2.63 |
| 样本内（16 期） | `indpct` | 20.0 | 0.050 | 2.41 |
| | `hyst` | 12.0 | 0.109 | 2.77 |
| | 叠加 | 14.8 | 0.080 | 2.68 |
| **样本外（15 期）** | `indpct` | 20.0 | 0.050 | 2.42 |
| | `hyst` | 12.3 | 0.109 | 2.72 |
| | 叠加 | 17.5 | 0.063 | 2.58 |

**三个区间方向完全一致** → 不是某一阶段的偶然。

## 三、H2 证伪：两者选出的股票**几乎完全不同**

选股重叠度（Jaccard，1 = 完全相同）：

| 对比 | 全区间 | 样本内 | 样本外 |
|---|---|---|---|
| `hyst` vs 行业内 | 0.279 | 0.270 | **0.288** |
| 行业内 vs 原始 `topn` | 0.314 | 0.332 | 0.294 |
| **`hyst` vs 原始 `topn`** | 0.763 | 0.691 | **0.840（中位 1.000）** |
| 叠加 vs 行业内 | 0.372 | 0.331 | 0.417 |
| 叠加 vs `hyst` | 0.641 | 0.700 | 0.578 |

**`hyst` 与 `indpct` 的重叠只有 0.27~0.29**（三个区间一致）→
**它们选的是两批完全不同的股票** → **H2 证伪**。
"两者在做同一件事"这个直觉是错的，抵消发生在**暴露维度**上，不在**选股**上。

---

## 四、H1 证伪：`indpct` **不是**"隐含提高门槛"

对 `topn` 加不同的 `min_dy`，看与 `indpct` 选股的重叠度：

| `min_dy` | 全区间 J | 样本内 J | 样本外 J |
|---|---|---|---|
| 0.5% | 0.314 | 0.332 | 0.294 |
| 2.0% | 0.314 | 0.332 | 0.294 |
| 3.0% | 0.314 | 0.332 | 0.294 |
| 4.0% | 0.314 | 0.332 | 0.294 |
| 5.0% | 0.314 | 0.332 | 0.294 |
| 6.0% | 0.314 | 0.332 | 0.294 |
| 7.0% | 0.314 | 0.332 | 0.294 |
| **8.0%** | **0.284** | **0.279** | **0.289** |

**两个结论**：

1. **`indpct` 与任何门槛的 `topn` 重叠度都只有 0.28~0.33** →
   它**不是**靠提高门槛起作用，而是**真正的选股规则改变**（换掉约 70% 的持仓）→ **H1 证伪**。
2. ⚠️ **`min_dy` 从 0.5% 到 7.0% 的重叠度完全相同（0.314）** →
   这些门槛值**全都不 binding**。原因：合格池里股息率前 20 名的 dy 本来就都高于 7%
   （`topn` 组合的最低股息率中位 **7.90%**）。
   → **这是本项目的第 4 个「参数没生效」实例**
   （前三个：`hyst` 默认 `entry=4%` 退化成 `topn`、引擎 `topk*2` 静默守卫、
   `hyst` 下 `N≥40` 时 N 失去意义）。
   **`min_dy=8.0` 才开始 binding** —— 这也解释了为什么 `hyst` 要选 `entry=8`。

## 五、⚠️ 意外发现：`hyst` 的样本外增量**只由少数日期贡献**

顺着 H1 的发现往下查，得到一个比"叠加无增量"**更硬**的理由：

| 区间 | 调仓日数 | `hyst` 与 `topn` 选股**完全相同**的日期 | `entry=8%` **binding** 的日期 |
|---|---|---|---|
| 全区间 | 31 | 15（**48%**） | 17/31 |
| 样本内 | 16 | 5（**31%**） | 12/16 |
| **样本外** | 15 | **10（67%）** | **5/15** |

**读法**：

- **样本外 15 个调仓日里，10 个（67%）`hyst` 与 `topn` 选出完全相同的股票** ——
  因为样本外 `topn` 组合的最低股息率中位是 **8.36% ≥ entry=8%** → **门槛根本不 binding**。
- `hyst` 样本外的 **+2.75pp 增量全部来自剩下那 5 个日期**。
- 对比 `indpct`：与 `topn` 的 J 中位 **0.290**，**每一个日期都不同**（15/15）。

→ **`hyst` 的样本外证据基础（5 个日期）比 `indpct`（15 个日期）薄得多。**
→ **这独立地支持了定稿决定（不用 `hyst`）**，而且理由比"叠加无增量"更直接：
**它的门槛在样本外大部分时间不生效，收益集中在少数几期。**

⚠️ 同时这也解释了 `docs/个股线_四进三出阈值检验.md` 里那条"⚠️ `entry=8` 贴着生效边界
（7 不生效、8 生效）"的担忧 —— **在 `hold=60` + `≤10%` + `≥2次` 的过滤下，
`entry=8` 在样本外也是"半个边界"**：67% 的日期不生效。

## 六、对「还有没有第三个改进方向」的回答

**已知的两条路在行业暴露上互相打架**（第二节）→ 不能叠加。
那**理论上剩下的路**是：**在 `hyst` 的高门槛候选池内做行业中性化**（`hyst` + 行业配额），
既保住门槛又保住行业分散。

**这条路实测已被否决**（`docs/个股线_四进三出阈值检验.md` §11.4、
`results/n_sens_backtest.csv`）：`hyst`+行业配额 样本外只有 **9.34%**（无税）/ **8.88%**（税后），
因为**双重约束把持仓压到 12~13 只**（候选池不足 20）。

→ **结论：在当前数据与信号质量下，样本外 ~11% 就是这个策略的天花板。**

三种形态的样本外（税后，10 万真实）全部落在 **10.1% ~ 11.0%**：

| 形态 | 样本外 10 万真实 |
|---|---|
| 行业内百分位（★定稿） | 10.10% |
| `hyst 8/4` | 10.62% |
| `hyst`+行业内 | 10.74% |

**要突破这个天花板，需要的是新的信息源（新因子 / 新数据），不是新的组合规则。**
继续在 `N` / `hold` / `entry` / `exit` / 行业约束上排列组合，收益会一直在 10~11% 附近打转，
且**每多调一个参数，过拟合风险就多一分**。

## 七、必须说清的局限

1. **"行业 dy 暴露"是本脚本自造的指标**（Σ 行业权重 × 行业池内平均 dy），
   不是标准指标。它只用来说明"方向"，**不要拿绝对值去和别的报告比**。
2. **行业分类是「当前」标签，非 point-in-time** → 画像存在轻微前视
   （与 `docs/个股线_行业中性化.md` 同一局限）。
3. **样本外只有 15 个调仓日**，`hyst` 的"5 个 binding 日期"更是小样本 →
   **"hyst 的证据基础薄"这个判断本身也有不确定性**；
   但它与"叠加无增量（4 个 hold 均值 −0.64pp）"相互独立、方向一致，两条证据同向。
4. **只测了 `hold=60` / `N=20`**。机制（行业暴露方向相反）在 `hold`/`N` 邻域上
   未逐一验证，但第二节三个区间的方向完全一致 → 可信度较高。
5. **重叠度用 Jaccard，等权处理** —— 组合是等权的，所以 Jaccard 与"权重重叠"一致；
   若将来改成非等权，需换成加权重叠度。

## 九、一句话

**共享机制不是"选同一批股票"（两者选股重叠只有 0.29），而是"在行业暴露这个维度上方向相反"：
`indpct` 把行业 HHI 腰斩（0.107→0.050）、行业数 12→20；
`hyst` 则完全不改善行业暴露（0.109 / 12.3，与 `topn` 一模一样），
它的 8% 高门槛天然偏向高股息行业，把 `indpct` 刚建立的行业分散又吃掉一部分
（叠加后 HHI 0.063、行业数 17.5）→ 叠加必然互相抵消。**

**顺带查出一个比"叠加无增量"更硬的否定理由**：
**`hyst` 在样本外 15 个调仓日里有 10 个（67%）与 `topn` 选出完全相同的股票** ——
门槛根本不 binding，+2.75pp 全部来自剩下 5 个日期。**证据基础比 `indpct` 薄得多。**

**所以：`indpct` 是真正的选股规则改变（每期都不同），`hyst` 是少数日期的门槛效应。
定稿选前者，理由充分。**

**最后一个判断**：三条路（行业分散 / 高门槛滞留 / 高门槛+行业配额）都试过了，
样本外全部落在 **10.1%~11.0%** → **~11% 是当前信号质量下的天花板。
要突破需要新信息源，不是新组合规则。**
