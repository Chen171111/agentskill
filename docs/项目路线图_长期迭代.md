## 二、长期迭代的六条设计原则（写进纪律，不靠自觉）

这些不是口号，每一条都有 `tools/selftest.py` 或铁律兜底：

| # | 原则 | 兜底机制 |
|---|---|---|
| 1 | **单一来源**：口径 / 成本 / 判据只能有一处实现 | `tools/costs.py`；selftest 断言"costs.py 之外无定义" |
| 2 | **静默是 bug**：任何跳过/兜底必须计数或报错 | 引擎 `n_skip` 计数；`require_adj_mode` 缺参即 raise；铁律 5/17 |
| 3 | **一个改动只动一个变量** | 引擎+口径同时变更时，必须建"锁定一个"的同口径回归对照（铁律 19） |
| 4 | **参数必须证明 binding** | "是否生效"的判据 = **结果与基线不同**，不是代理变量（铁律 8） |
| 5 | **数字可追溯** | 报告里每个数字要能追到 `results/` 某个文件 + 一条命令 |
| 6 | **改动前后跑自检** | `tools/selftest.py`（13 项，< 60 秒，退出码非 0 = 回归） |

**统一验收标准（五闸门，缺一不算通过）**：

| 闸门 | 判据 |
|---|---|
| ① 样本内外同号 | 样本内与样本外**同时**为正，且方向一致 |
| ② 邻域同向 | 至少 3 个邻域点（`hold` / 持仓数 / 权重方式）**全部同向** |
| ③ 净成本后仍为正 | 用**完整成本模型**（含最低佣金、印花税、滑点）后仍有增量 |
| ④ 增量而非冗余 | 与既有因子秩相关 <0.5 **且**样本外增量 > 0（只满足相关性的不算） |
| ⑤ 机制可解释 | 能给出"它在哪个暴露维度上起作用"的诊断（对照铁律 12） |

**流程**：任一候选 → 五闸门 → 过则进定稿；不过则**追加到已证伪清单**（含结论与量级）。

## 四、阶段与优先顺序

| 阶段 | 时间 | 内容 | 优先理由 |
|---|---|---|---|
| **P0** | 本周 | 收尾：重跑 / 回灌 / Brinson 复核 / 回归 / 提交 | **不回灌，所有数字都不可引用** |
| **P1** | 2~4 周 | 数据与自动化加固：A1 增量落盘、A2 周度任务、A3 新鲜度、A5 守卫库、C1 差异台账、C2b 影子权重、C5 连接重试 | 这三件直接决定"能不能长期无人值守地跑" |
| **P2** | 1~2 月 | 前向验证：C2 纸面跟踪 ≥2 期；ETF Faber ≥8 周 → 决策 | 补"真实前向数据"这个回测无法替代的证据 |
| **P3** | 2~6 月 | 策略扩展：B1 `dy_fwd` 事件型 → B2 财务质量 → B3 ETF 扩池 | 找**新信息源**，不是新规则 |
| **P4** | 半年+ | C3 小资金实盘 → C4 定稿资金；B4（需分钟数据） | 只有前向过关才配钱 |

**优先顺序的三条理由**：
1. **P0 必须最先** —— 现在 9 份文档的数字不可引用，任何基于它们的新研究都是空中楼阁。
2. **P1 排在策略之前** —— 无人值守的可靠性是"长期迭代"的前提；否则每次都要人盯着，项目停摆。
3. **B1 排在 B2 之前** —— `dy_fwd` 数据已在手、零新增成本，且是"事件型"用法（与现有排序机制正交），
   比接新数据源试错更划算。
